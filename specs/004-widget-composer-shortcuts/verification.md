# شواهد — ۲۰ اکتبر ۲۰۲۶

۵۵ آزمون Node شامل لینک‌های ناوبری امن، تاریخچهٔ مرورگر، Back دوم، بازکردن سریع، کلیک بیرون، draft/پاسخ در حال دریافت و fallback history موفق‌اند. PHP ظاهر/migration و WPCS موفق‌اند. WordPress واقعی مهاجرت با حفظ متن و رنگ، چهار لینک، hidden label، nonce/capability و رد URL ناامن/دکمهٔ پنجم را تأیید کرد.

Chrome محلی تا این مرحله، ذخیرهٔ چهار لینک در فرم native و دریافت روی HTML کش‌شده، حذف notice و label دیداری، focus بدون outline و ارسال داخل کادر را تأیید کرد. ابعاد دقیق قبلی در 1440×1000، 390×844 و 844×390 حفظ شدند. Back نخست/دوم، Forward و reload بدون مرحلهٔ مرده موفق بودند. × و کلیک بیرون، حفظ focus/draft و ناوبری عادی لینک بیرون موفق بودند. فرم native با خالی‌شدن یک متن سه لینک و با reset صفر لینک نمایش داد؛ بررسی scoped axe بدون violation بود. رگرسیون ارسال مصنوعی، لینک امن، بازیابی پس از reload، حفظ draft و retry پس از خطا، clear با تأیید و Escape هم موفق بود؛ Chrome هیچ خطای runtime نداشت. تغییر سیاست ۱۵روزه و خاموش‌شدن clear در WordPress محلی نیز بدون وجود notice اعمال شد. پنج تست Python بسته/انتشار، PHP settings/bridge/catalog و lint/WPCS موفق بودند. CI/Release و نصب تولید هنوز باید ثبت شوند.

تمام دادهٔ این آزمون محلی مصنوعی است. Android/iOS فیزیکی، Safari واقعی، multisite و بار گسترده آزموده نشده‌اند؛ بستن کیبورد مجازی توسط Back در اختیار سیستم‌عامل است.

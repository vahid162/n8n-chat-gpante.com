# GPante Support Chat 0.10.2

جست‌وجوی محصول روی نسخه‌های قدیمی WooCommerce که Store API آن‌ها فیلد `is_password_protected` ندارد کار می‌کند. وضعیت انتشار، رمز واقعی نوشته و نمایش عمومی محصول همچنان مستقل از این فیلد بررسی می‌شوند؛ مقدار صریح نامعتبر یا محافظت‌شده پذیرفته نمی‌شود.

این نسخه تمام اصلاحات 0.10.1 در تاریخچه، لینک‌های عمومی و عمر کوکی را دارد. مدل، سقف هزینه، تنظیمات و سیاست نگهداری تغییر نمی‌کنند.

برای ارتقای مستقیم از 0.10.0، migration افزایشی `006-expired-send-guards.sql` را یک‌بار بعد از005 با Main متوقف و تخلیه‌شده اجرا کنید؛ سپس Main1.7.1 و این افزونه را نصب کنید. اگر006 قبلاً اجرا شده است، دوباره اجرا نشود. ارتقا از0.10.1 فقط به تعویض افزونه نیاز دارد.

# شواهد — ۲۰ اکتبر ۲۰۲۶

۵۶ تست Node شامل marker خوشامد و حفظ نقش و refresh دیرهنگام، PHP appearance/settings/bridge/catalog، پنج تست Python بسته/انتشار و WPCS موفق‌اند. WordPress native، حذف فقط فیلد send و ذخیرهٔ معتبر بدون ارسال آن را با حفظ تنظیمات و نام دسترس‌پذیر تأیید کرد.

Chrome واقعی محلی، حذف فقط فیلد send از فرم و ذخیرهٔ بدون تغییر را تأیید کرد. دکمهٔ تنها و آخرین دکمه در مجموعهٔ سه‌تایی ۱۰۰٪ عرض ردیف و دو/چهار دکمه دو ستون برابر دارند. عرض welcome با فضای داخلی پیام‌ها برابر است. اختلاف مرکز دکمه، آیکون و textarea در ارتفاع عادی/تغییرکرده کمتر از یک پیکسل بود.

ابعاد دقیق 390×650، 374×650 و 390×366 به‌ترتیب در viewportهای 1440×1000، 390×844 و 844×390 حفظ شدند. ارسال واقعی مصنوعی از bridge محلی، کاربر را راست و دستیار را چپ نشان داد. متن بلند فارسی/انگلیسی بدون overflow افقی، کنترل‌های قابل دسترس، audit محدود بدون violation و صفر خطای runtime تأیید شدند. Release و نصب تولید هنوز انجام نشده‌اند. تمام دادهٔ آزمون محلی مصنوعی است؛ هیچ تماس مدل لازم نیست.

Safari/iOS/Android فیزیکی، multisite و بار گسترده در این تغییر آزموده نشده‌اند. پیگیری درخواست در حال تولید هنگام ترک صفحه و جلوگیری از ارسال تکراری، خارج از این اصلاح ظاهری و همچنان کار جدا هستند.

# نمایش خوانای پاسخ دستیار

درخواست: لینک‌های زیرخط‌دار به دکمه تبدیل شوند و جزئیات/ویژگی‌های محصول با جدول خوانا و تجربهٔ مناسب موبایل نمایش داده شوند.

- منبع نمایش همان متن API v1 است؛ فقط subset محدود Markdown شامل متن برجسته، پاراگراف، لینک مجاز و جدول شناخته می‌شود. HTML مدل اجرا نمی‌شود و کاربر عادی همچنان متن ساده می‌فرستد.
- لینک تأییدشده anchor واقعی با ظاهر دکمه، حداقل ارتفاع لمسی ۴۴ پیکسل، focus قابل مشاهده و مقصد/rel امن باشد. URL خامِ مجاز برچسب کوتاه داشته باشد؛ مسیرهای خصوصی و مقصدهای قبلاً ممنوع همچنان ممنوع‌اند.
- جدول معتبر دو تا چهار ستون و حداکثر ۲۰ ردیف داده دارد؛ caption، سرستون و عنوان ردیف برای دسترس‌پذیری حفظ شوند. جدول عریض در wrapper قابل پیمایش با صفحه‌کلید قرار گیرد. جدول ناقص/بیش از حد، بدون حذف مقدار به متن برگردد.
- پاسخ تازهٔ مدل با نام برجسته، توضیح کوتاه، جدول دو‌ستونیِ ویژگی‌های تأییدشده و CTA مستقل تولید شود؛ راهنمای شش ردیف در پرامپت برای اختصار است و تضمین شکلی مدل نیست. renderer سقف فنی ۲۰ ردیف دارد. برای سلام و سؤال ساده جدول لازم نیست. unknown، رایگان و واحد پول طبق دادهٔ واقعی باقی بمانند.
- ابعاد پنجره، جهت حباب‌ها، رنگ‌ها، تنظیمات، تاریخچه، خطا/retry، ورودی فوری و بودجهٔ فعلی حفظ شوند. REST، schema اتصال/ظاهر، SQL یا وابستگی تازه لازم نیست.
- نسخهٔ افزونه 0.5.0 و قالب پاسخ Main 1.2.3 مستقل منتشر شوند؛ ابتدا افزونهٔ سازگار نصب و سپس پرامپت هماهنگ شود. پوشش دستگاه فیزیکی، Safari و بار گسترده جداگانه است.

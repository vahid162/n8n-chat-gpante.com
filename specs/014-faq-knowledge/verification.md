# بررسی FAQ

پذیرش نهایی: ۲۲ اکتبر ۲۰۲۶. افزونهٔ رسمی **0.8.0** نصب و Main **1.4.1** منتشر و فعال است. [پیاده‌سازی](https://github.com/vahid162/n8n-chat-gpante.com/pull/36)، [اصلاح پذیرش](https://github.com/vahid162/n8n-chat-gpante.com/pull/37) و [Release قابل نصب](https://github.com/vahid162/n8n-chat-gpante.com/releases/tag/wordpress-v0.8.0).

## منبع و مرورگر صفحه

صفحهٔ منتشرشده در بررسی ۲۱ اکتبر ۴۵ سؤال در شش موضوع داشت. Chromium و Firefox: لینک مستقیم CDR، بستن با Enter و بازکردن با Space، سه نام کورل با سه نتیجه، ضخامت با شش نتیجه، نسخهٔ 2024 و عبارت ناموجود با صفر نتیجه، Enter بدون reload و نمایش همهٔ سؤال‌ها موفق بودند. سه اندازهٔ 1440×1000، 390×844 و 320×568 بدون overflow افقی یا خطای runtime بودند؛ POSTها مسدود بودند و صفحه و noindex ویرایش نشدند.

آداپتر نامزد روی همان محتوای واقعی، DXF، شیار/زبانه، طراحی، ایمیل و کورل را پیدا کرد؛ نسخهٔ ناموجود خالی بود. هر ۱۱ پاسخ شامل راهنما/مقالهٔ قبلی از validator واقعی Node گذشتند. خواندن سرد FAQ حدود ۲٫۶ ثانیه و جست‌وجوی بعدی از کش عمومی حدود یک میلی‌ثانیه در callback بود؛ این زمان کامل پاسخ مدل نیست.

## آزمون و بازبینی

- ۹۰ آزمون Node، ۶۹ assertion بومی FAQ، ۷۳ بررسی WordPress/WooCommerce کاتالوگ، ۲۶ query، PHP تنظیمات/ظاهر/bridge/preview، WPCS و پنج تست بسته موفق بودند. fixtureها فقط در WordPress جداگانه بودند و پاک شدند؛ دیتابیس آزمایشی به حالت توقف اولیه برگشت.
- آزمون بومی، جفت سؤال‌وجواب، محدودهٔ صفحه، حذف script/embed، مرجع رسمی، سؤال تازه، جواب بلند، جست‌وجوی متن کامل، نسخهٔ صریح، شمار/صفحه‌بندی، اولویت عنوان پیش از صفحه‌بندی، کش/ابطال با تغییر متا، خصوصی/رمزدارشدن و خطای HTTP/ساختار/سند ناقص را پوشش داد.
- تشخیص اولیهٔ انتهای HTML کامنت بی‌خطرِ کش را رد می‌کرد؛ کنترل اصلاح و آزمون پذیرش کامنت و رد سند قطع‌شده اضافه شد. بازبینی مستقل ناهماهنگی مهلت داخلی ۱۲ ثانیه با ابزار ۱۰ثانیه‌ای را یافت؛ مهلت داخلی هشت ثانیه شد و آزمون دوباره گذشت.
- Main 1.4.0 و سپس نامزد 1.4.1 با activation و SDK strict نصب‌شدهٔ n8n، با صفر warning موفق شدند. مسیر API فقط هشدار قدیمیِ تعداد جعبه‌های canvas را داشت؛ چیدمان نامرتبط تغییر نکرد. بازبینی‌های مستقل و Codex روی GitHub ایراد باز نداشتند؛ CI شامل SQL/آرشیو موفق بود.

## پذیرش پاسخ واقعی

پذیرش اولیهٔ Main1.4.0 فقط موفقیت HTTP نبود: هر چهار درخواست با usage کامل ذخیره شدند، ولی پاسخ شیار ادعای جهت‌دارِ نیامده در FAQ اضافه کرد و پرسش ایمیل از تعریف عمومی کاربر در مقررات، الزام حساب را اشتباه نتیجه گرفت. Main1.4.1 انتخاب FAQ برای روند خرید و بازنویسی وفادار/مرجع‌دهی را روشن کرد؛ مدل یا الگوریتم جست‌وجو عوض نشد.

پنج پرسش تازه در Firefox روی نسخهٔ منتشرشدهٔ 1.4.1 بررسی شدند:

| پرسش | نتیجهٔ مشاهده‌شده |
| --- | --- |
| DXF چیست؟ | تعریف مرتبط و دکمهٔ همان سؤال FAQ |
| زبانه در شیار جا نمی‌رود | مقایسهٔ ضخامت/شیار/مقیاس/عرض برش و اتصال آزمایشی، بدون ادعای قبلی دربارهٔ جهت تغییر؛ دو مرجع مرتبط |
| هماهنگی طراحی اختصاصی | دکمهٔ تماس و تلگرام رسمی و مرجع FAQ؛ اطلاعات نمونه اختیاری، بدون ثبت سفارش/پیام یا قیمت/زمان ساختگی |
| خرید بدون ایمیل | ایمیل اختیاری، تلفن الزامی و فرم واقعی تسویه‌حساب مرجع نهایی؛ بدون استنتاج الزام حساب از مقررات |
| درخواست صریح متن مقررات | دکمهٔ صفحهٔ مقررات؛ مسیر راهنمای قبلی محفوظ |

همهٔ لینک‌ها دکمه با وزن قلم 400 بودند و پاسخ/لینک پس از reload بازیابی شد؛ خطای runtime دیده نشد. هر پرسش دو تماس مدل و usage کامل داشت. زمان ارسال تا پاسخ در این پنج نمونه حدود ۷ تا ۹ ثانیه بود؛ تضمین عملکرد نیست. Chromium نیز در پذیرش اولیه لینک FAQ/طراحی و تاریخچه را بررسی کرد. لینک تلگرام از صفحهٔ رسمی استخراج شده است؛ پیامی ارسال یا دسترسی شبکهٔ Telegram مستقلاً تأیید نشد.

## استقرار و حدود

ZIP رسمی، tag/commit، SHA256 و هر ۱۳ فایل نصب‌شده با منبع برابرند. کل runtime/ظاهر، enabled، کلیدها، policy/revision، قالب و افزونه‌های فعال حفظ شدند؛ cache فقط همین سایت تازه شد و rollback خصوصی بیرون webroot است. Main فعال و draft با نامزد تأییدشده برابرند؛ گراف ۶۹ نود، settings و credential bindingها محفوظ و هر ۲۴ workflow دیگر ثابت‌اند. بودجهٔ ۲ دلار و مدل/تاریخچه/schemaها تغییر نکردند، lease فعال در پایان صفر و آخرین اجرای طبیعی Retention موفق بود.

مهارت canonical و ZIP مستقل آن 0.10.1 هستند. تغییر متای Elementor کش عمومی را باطل می‌کند؛ سؤال تازهٔ بومی بدون نگاشت دوستانه به خود صفحه لینک می‌گیرد. تغییر ساختار Elementor یا عبور از مرز منابع به بررسی آداپتر نیاز دارد و خطای صریح می‌دهد.

Safari/دستگاه فیزیکی، بار گسترده و همهٔ صورت‌بندی‌های زبان طبیعی آزمایش نشده‌اند. این نمونه‌ها صحت همهٔ پاسخ‌های آیندهٔ مدل را تضمین نمی‌کنند؛ کیفیت موارد واقعی در نگهداری بعدی بررسی شود.

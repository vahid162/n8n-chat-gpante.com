# بررسی Main 1.2.2

در ۲۰ اکتبر ۲۰۲۶، ۶۲ آزمون Node گذشتند: batchهای یک/دو/سه‌تایی، حفظ ترتیب و IDها، جلوگیری از تماس مدل وسط صف، ظرفیت باقی‌مانده، ابزار/ID نامعتبر، خروجی ناقص و کدهای ثابتِ بدون متن provider. پاسخ موفق در شکست حسابداری بسته می‌ماند.

اعتبارسنجی activation، SDK strict و کامپایل Code روی نسخهٔ نصب‌شدهٔ n8n برای گراف ۶۹نودی، بدون warning گذشت. سه اجرای native روی کپی غیرفعال و مستقل انجام شد؛ مدل و حسابداری مصنوعی و HTTP واقعی بومی به fixture فقط-loopback بودند:

| سناریو | نتیجه |
| --- | --- |
| سه ابزار معتبر در یک پاسخ | سه خواندن HTTP به‌ترتیب، همهٔ IDها و داده‌ها صحیح، مدل دوم با tools=none |
| آرگومان نامعتبر بین دو ابزار معتبر | دو HTTP، یک invalid_query، دادهٔ first/third و ترتیب ID صحیح با paired-item |
| ID تکراری | صفر ابزار و کد model_tool_duplicate_id |

این اجراها صفر تماس واقعی مدل و صفر نوشتن دفتر مالی تولید داشتند؛ کپی‌ها آرشیو و fixture متوقف شدند. آزمون PostgreSQL در دیتابیس جدا و با rollback، ذخیره/نمایش کد دقیق در API فعلی مدیریت و مرز نگهداری را تأیید کرد؛ دیتابیس موقت حذف شد. migration تولید لازم نیست.

این شواهد علت دقیق ۹ خطای تاریخی را اثبات نمی‌کنند؛ پاسخ خام آن‌ها موجود نیست. خطاهای جدید علت دقیق شرط ردشده را ثبت می‌کنند. سازگاری تمام خروجی‌های احتمالی provider یا بار گسترده از این آزمون‌ها نتیجه نمی‌شود.

نسخهٔ نهایی با مسیر رسمی MCP منتشر و active=true و نسخهٔ فعال برابر draft بازخوانی شد؛ نودها، connections، settings و توضیح با نامزد اعتبارسنجی‌شده برابرند. Credentials و جای نودهای قبلی حفظ شدند. هر ۲۱ workflow قبلی، شامل Admin/Retention، بدون تغییر و سه کپی همین آزمون آرشیو هستند. هشدار نمای کلی canvas دربارهٔ تعداد زیاد نودهای بدون گروه، همان وضعیت قبلی است؛ اعتبارسنجی اجرایی warning نداشت. سرویس restart نشد؛ افزونه، قالب، SQL تولید، runtime/policy و سقف بودجه تغییر نکردند.

Chrome تولید با TLS معتبر و نشست تازه، یک پرسش مصنوعی برای باکس آجیل و جا دستمال کاغذی فرستاد: history/send/history همگی HTTP 200، پاسخ دارای دو لینک محصول و دو پیام مطابق در تاریخچه بود. زمان درخواست مرورگر حدود ۱۰٫۳ ثانیه و زمان ثبت‌شدهٔ turn حدود ۸٫۱ ثانیه؛ دو تماس واقعی مدل، usage کامل و هزینهٔ محافظه‌کارانهٔ همین turn حدود ۰٫۰۰۴۹۳ دلار بود. ledger ماهانه در بازهٔ کار از ۰٫۰۸۶۹۷ به ۰٫۰۹۵۵۶۵۹ دلار رسید؛ این افزایش شامل ترافیک هم‌زمان است و فقط به آزمون منتسب نمی‌شود. lease فعال در پایان صفر بود. مرورگر اختصاصی بسته شد. این تأیید زنده، شکل درخواست‌های ابزار داخل پاسخ provider را نشان نمی‌دهد؛ آزمون‌های native آن بخش را جدا پوشش می‌دهند.

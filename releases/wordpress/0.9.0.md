# GPante Support Chat 0.9.0

برگه‌های عمومی منتشرشده، مقاله‌ها و محصولات از جست‌وجوی مشترک سایت در دسترس دستیار قرار می‌گیرند. انتخاب دستی برگه لازم نیست؛ متن ایستای Elementor نیز قابل جست‌وجو است. Main 1.6.0 برای درخواست آموزش، نصب نرم‌افزار یا محصول منبع مناسب را انتخاب و در صورت نیاز بخش مرتبط صفحه را می‌خواند.

ابتدا این افزونه و سپس Main 1.6.0 منتشر شود؛ عقب‌گرد به ترتیب معکوس است. تنظیمات اتصال/ظاهر، FAQ، حافظه، مدل و بودجهٔ قبلی حفظ می‌شوند. مهاجرت پایگاه داده لازم نیست. فقط محتوای عمومی مجاز خوانده می‌شود؛ فرم و دادهٔ حساب مشتری منبع دانش نیستند.

بررسی‌های قرارداد، WordPress بومی، بسته‌بندی و شواهد استقرار در `specs/016-site-knowledge/verification.md` ثبت می‌شوند. کوتاه‌شدن متن و شکست منبع صریح‌اند؛ پوشش منبع تضمین صحت همهٔ پاسخ‌های مدل نیست.

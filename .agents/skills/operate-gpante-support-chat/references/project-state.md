# وضعیت جاری پروژهٔ چت جی‌پانته

تاریخ ثبت: ۱۹ اکتبر ۲۰۲۶. مخزن مرجع: [n8n-chat-gpante.com](https://github.com/vahid162/n8n-chat-gpante.com).

این فایل حافظهٔ کاریِ ثبت‌شده است. وضعیت زنده، مجوزهای فعلی و درخواست تازهٔ کاربر بر مشاهده‌های تاریخی مقدم‌اند. کلید، مسیر خصوصی، اطلاعات مشتری و خروجی خام اجرا در این فایل قرار نمی‌گیرد.

## تصمیم فعلی کاربر و دامنهٔ کار انجام‌شده

- کاربر خواسته است محصول کامل با پوشش کل کاتالوگ مجاز عمومی ساخته شود. پیشنهاد قبلیِ محدودکردن شروع به یک مجموعهٔ کوچک محصول کنار گذاشته شده است.
- دستور این مرحله فقط تکمیل مهارت و مستندات آن است؛ ساخت/اجرای چت، تست هزینه‌دار مدل و انتشار روی سایت مجاز نشده‌اند.
- مهارت `operate-gpante-support-chat` نسخهٔ ۰٫۱٫۰، راهنمای پروژه و README متناسب با این تصمیم ایجاد شدند. وجود متن مهارت اثبات استقرار محصول نیست.
- مهارت قدیمی `operate-woo2-n8n` فقط مرجع روش کار بود؛ وابستگی این پروژه نیست و نباید بازنویسی شود.

## شواهد تکمیل مهارت

- اعتبارسنج رسمی `skill-creator/scripts/quick_validate.py` موفق بود. ساختار YAML، متن فراخوانی مهارت، پیوندهای داخلی و اختلاف فایل‌ها بررسی شدند؛ انتخاب خودکار مهارت با تنظیم پیش‌فرض فعال مانده است.
- یک ارزیاب مستقل، درخواست فارسیِ «فقط بررسی» را روی شواهد کاملاً ساختگی اجرا کرد. صفحه‌بندی ناقص و اختلاف وضعیت ثبت‌شده با پیش‌نویس را تشخیص داد و به‌دلیل نبود تعریف نسخهٔ منتشرشده، علت خرابی تولید را قطعی اعلام نکرد. هیچ فایل یا سرویس واقعی در این آزمون تغییر نکرد.
- پیوند نصب Codex به منبع همین checkout ساخته شد و یکسانی محتوای ورودی مهارت از مسیر نصب و منبع تأیید شد. منبع مستقل و تکراری برای نصب ایجاد نشده است.
- این شواهد فقط اعتبارسنجی مهارت و مستندات‌اند؛ کیفیت چت، عملکرد مدل، کل کاتالوگ و استقرار محصول همچنان آزموده نشده‌اند.

## وضعیت واقعی محصول

| جزء | آخرین وضعیت تأییدشده |
| --- | --- |
| Workflow اختصاصی چت سایت | در بازرسی ۱۹ اکتبر ۲۰۲۶ وجود نداشت؛ شناسه و نسخهٔ فعال تعریف نشده |
| ویجت سایت | نصب یا منتشر نشده |
| مدل اختصاصی چت | انتخاب و آزمایش نشده؛ هزینه یا کیفیت پاسخ آن اندازه‌گیری نشده |
| حافظهٔ مکالمه | جدول یا اتصال اختصاصی ایجاد نشده |
| ابزارهای اختصاصی چت | ساخته نشده؛ فقط APIهای عمومی زیر بررسی شده‌اند |
| نمایه/embeddings | ایجاد نشده؛ انتخاب ضروری یا قطعی نیست |
| احراز هویت مشتری و سفارش/دانلود | طراحی و پیاده‌سازی نشده |
| استقرار، بار هم‌زمان و کیفیت فارسی | آزمایش نشده |
| Spec Kit همین مخزن | در بررسی اولیه راه‌اندازی نشده؛ spec/plan/tasks/constitution ساخته نشده‌اند |

آرشیو یک دموی قدیمی Chat Trigger و چت تلگرام مدیریتی woo2، پیاده‌سازی چت عمومی این محصول نیستند. پیش از کار عملیاتیِ بعدی، وضعیت Workflowها دوباره بررسی شود.

## هدف محصول و اصول تأییدشده

- سایت `https://gpante.com` مبتنی بر WordPress و WooCommerce است؛ سرور آن با سرور n8n متفاوت است.
- رابط، چت شناور فارسی و راست‌به‌چپ است. انتخاب محصول، پرسش مشخصات و راهنمای خرید/دانلود عمومی از نیازهای اصلی‌اند.
- تمام محصولات واجد شرایط نمایش/کشف عمومی باید قابل جست‌وجو باشند. محصول پنهان سیستمی، محتوای خصوصی و فایل فروشی به دانش عمومی وارد نمی‌شوند.
- پرداخت مصرف API مدل پذیرفتنی است؛ هزینهٔ لایسنس افزونه یا اشتراک پلتفرم چت مطلوب کاربر نیست.
- توسعهٔ بعدی می‌تواند پشتیبانی فنی، حساب مشتری، سفارش/دانلود و ارجاع انسانی را پوشش دهد؛ قابلیت خصوصی یا تغییردهنده به نیازمندی و مجوز خودش نیاز دارد.
- گردش‌کارهای فعال woo2 روی همین n8n عملیاتی‌اند و باید حفظ شوند. ابزارهای مدیریت آن‌ها به دستیار عمومی متصل نمی‌شوند.

## شواهد اتصال عمومی

مشاهده‌های زیر در ۱۹ اکتبر ۲۰۲۶ از داخل کانتینر n8n انجام شدند؛ فراخوانی مدل یا اجرای Workflow نبودند.

- `GET https://gpante.com/wp-json/wc/store/v1/products/49304` بدون کلید مدیریتی پاسخ ۲۰۰ داد؛ محصول «فایل برش لیزر باکس آجیل دامان» بود.
- جست‌وجوی «باکس آجیل» از Store API موفق بود.
- جست‌وجو با نمایش عمومی و رابطهٔ AND میان DXF، ضخامت ۲٫۷ و MDF، مجموع ۷ نتیجه گزارش کرد. پنج نتیجه خوانده و انطباق ویژگی‌های آن‌ها بررسی شد؛ این عدد معیار ثابت آینده نیست.
- ضخامت ناموجود، پاسخ موفق با صفر نتیجه داد؛ با خطای ارتباط تفاوت دارد.
- `GET https://gpante.com/wp-json/wp/v2/posts?per_page=3&_fields=id,link,title` پاسخ موفق داد و مجموع ۱۸ نوشته گزارش شد. تأیید راهنماهای پشتیبانی هنوز انجام نشده است.
- موجودبودن این endpointها، کامل‌بودن جست‌وجوی معنایی/کل کاتالوگ، سیاست نمایش پنهان‌ها یا کیفیت چت نهایی را اثبات نمی‌کند.

نام ویژگی‌های واقعی:

| مفهوم | taxonomy | نمونهٔ slug |
| --- | --- | --- |
| فرمت | `pa_file-format` | `dxf` |
| ضخامت | `pa_thickness` | `2-7` |
| متریال | `pa_materials-required` | `mdf` |

پارامترهای ترکیبِ آزمایش‌شده:

```text
search=باکس آجیل
catalog_visibility=visible
attribute_relation=and
attributes[0][attribute]=pa_file-format
attributes[0][slug]=dxf
attributes[1][attribute]=pa_thickness
attributes[1][slug]=2-7
attributes[2][attribute]=pa_materials-required
attributes[2][slug]=mdf
```

این نمونهٔ فیلتر، فهرست ثابت محصولات یا تضمین پوشش تمام حالت‌های visibility نیست. سیاست واجدشرایط‌بودن و صفحه‌بندی باید برای محصول کامل بررسی شود. قیمت نمونه با واحد IRT/تومان و `currency_minor_unit=0` برگشت؛ مبلغ تاریخی را در پاسخ آینده ثابت فرض نکن.

## زیرساختِ آخرین بازرسی؛ مرجع تاریخی

| مورد | مشاهدهٔ ۱۹ اکتبر ۲۰۲۶ |
| --- | --- |
| n8n | کانتینر `n8n_gpx`، نسخهٔ ۲٫۴۳٫۷، حالت `regular`؛ Queue Mode فعال نبود |
| داده | PostgreSQL 17.11؛ `project_db` برای دادهٔ برنامه، جدا از دیتابیس داخلی n8n |
| HTTPS | `https://n8n.gpantex.com` پشت Nginx؛ health/readiness موفق بود |
| پراکسی | `N8N_PROXY_HOPS` تنظیم نشده و `X-Forwarded-Proto` در مسیر عمومی دیده نشده بود؛ پیش از انتشار بررسی و اصلاحِ مجاز لازم است |
| منابع لحظه‌ای | ۱۶ پردازندهٔ منطقی، حدود ۳۰ گیگابایت RAM، ۱۸ گیگابایت حافظهٔ در دسترس و ۴۰ گیگابایت دیسک آزاد؛ دیسک حدود ۸۷٪ مصرف‌شده |
| دسترسی عملیاتی | اتصال SSH/ترمینال، Docker و خواندن متادیتای PostgreSQL بررسی شد؛ MCP اختصاصی n8n یا احراز هویت API آن تأیید نشده است |

وجود منابع و موفقیت readiness، تضمین ظرفیت چت نیست. مقادیر متغیر باید در زمان تصمیم عملیاتی دوباره خوانده شوند.

## طرح پیشنهادی؛ هنوز انتخاب یا استقرار نهایی نیست

- Workflow مستقل چت با ابزارهای محدودِ جست‌وجو، خواندن محصول و خواندن راهنما.
- ویجت `@n8n/chat` با فارسی‌سازی و CSS راست‌به‌چپ؛ افزودن از امکانات موجود سایت پس از انتخاب و آزمون.
- استفاده از PostgreSQL موجود برای حافظهٔ مجزای نشست‌ها با دسترسی و نگهداری مشخص.
- جست‌وجوی مستقیم بر اساس ویژگی‌ها نقطهٔ شروع قابل بررسی است؛ انتخاب نمایه، همگام‌سازی یا embeddings به نیاز کل کاتالوگ و کیفیت جست‌وجو وابسته است.
- توسعه به بخش‌های حساب مشتری و ارجاع انسانی، بدون دادن مجوزهای آن‌ها به مسیر عمومی.

## تصمیم‌ها و کار بعدی

قدم بعدی پس از تکمیل این مهارت، تعریف نیازمندی‌های محصول کامل و معیارهای پذیرش است؛ کاربر اجرای این مرحله یا پیاده‌سازی را در دستور فعلی نخواسته است.

موضوع‌های باز: پرسش‌های پرتکرار واقعی، منابع راهنمای تأییدشده، سیاست دقیق نمایش محصولات، مدل و بودجه، اهداف زمان پاسخ/هم‌زمانی، روش احراز هویت مشتری، مسیر ارجاع انسانی، مدت نگهداری و حذف تاریخچه، و روش انتشار و بازگشت.

پس از ایجاد واقعی هر جزء، شناسه/نسخهٔ واقعی، وضعیت انتشار، تاریخ بررسی و نتیجهٔ آزمون همان جزء در این فایل ثبت شود. دربارهٔ پوشش کل کاتالوگ، نمونه‌گیری آزمون و پوشش واقعی تولید جداگانه گزارش بده.

فایل نصب `gpante-support-chat-wordpress-0.2.1.zip` همراه `SHA256SUMS` در Assets است. Source code ZIP بستهٔ نصب وردپرس نیست. نسخه‌های منتشرشدهٔ قبلی و تگ‌هایشان تغییر نکرده‌اند.

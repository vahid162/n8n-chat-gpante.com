تنظیم متن و رنگ چت از پیشخوان WordPress اضافه شد. در «چت پانته ← ظاهر»، متن‌های اصلی و هشت رنگ را تغییر دهید یا ظاهر پیش‌فرض را برگردانید. رنگ‌های ناخوانا و دادهٔ نامعتبر ذخیره نمی‌شوند.

تنظیمات ظاهر مستقل از اتصال و سیاست گفتگو هستند. تغییر خوشامدگویی دستور مدل را عوض نمی‌کند. صفحات کش‌شده در بارگذاری بعدی، ظاهر تازه را از مسیر عمومی و بدون تماس مدل دریافت می‌کنند.

بستهٔ قابل نصب: `gpante-support-chat-wordpress-0.3.0.zip`؛ صحت دانلود را با `SHA256SUMS` بررسی کنید. برای ارتقا از 0.2.x هیچ migration یا تغییر n8n لازم نیست؛ کش صفحات و assetهای سایت را پس از ارتقای فایل‌ها تازه کنید. نصب تازه همچنان به اتصال backend آماده نیاز دارد.

# GPante Support Chat 0.10.1

تاریخچهٔ گفتگو میان تب‌ها ترتیب درست را حفظ می‌کند؛ شکاف صفحه‌بندی و تغییر سیاست هنگام خواندن پیام‌های قدیمی، جدیدترین صفحه را دوباره قابل دسترسی می‌کنند. لینک دقیق صفحات عمومی حساب، سبد و تسویه‌حساب قابل کلیک است؛ مسیرهای خصوصی همچنان محدودند.

همراه Main 1.7.1، تطبیق ضخامت اعشاری، نسخهٔ صریح CDR و متن یونیکد اصلاح شده است. مدل، بودجه، سقف ابزار/تماس، تمام منابع عمومی و تنظیمات مدیر حفظ می‌شوند.

برای ارتقا از 0.10.0، migration افزایشی `006-expired-send-guards.sql` پس از005 و با Main تخلیه‌شده اجرا شود؛ سپس Main1.7.1 و افزونه ارتقا یابند. شناسه‌های ارسال بدون متن، تا۳۰روز بی‌فعالیتی نشست با۵دقیقه حاشیهٔ پایان درخواست برای جلوگیری از نوبت پولی تکراری نگهداری می‌شوند. متن گفتگو همچنان حداکثر۳۰روز است و دفتر هزینه حذف یا refund نمی‌شود. این یادداشت، شاهد نصب یا انتشار زنده نیست.

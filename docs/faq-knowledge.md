# منبع FAQ

`Knowledge_Search` سه منبع مستقل دارد: `articles` برای مقاله، `guides` برای مقررات/تماسِ مجاز قبلی، و `faq` برای سؤال‌وجواب‌های صفحهٔ رسمی Elementor. منبع FAQ پارامترهای search و page دارد و categoryId یا URL/شناسهٔ صفحه از مدل نمی‌گیرد. تعداد ابزارها و سقف تماس عوض نمی‌شود.

مهلت داخلی خواندن FAQ هشت ثانیه است تا داخل مهلت ده‌ثانیه‌ای ابزار n8n، فرصت پردازش یا خطای کنترل‌شده باقی بماند.

افزونه فقط نسخهٔ ناشناس و عمومی صفحهٔ ثابت را از HTTPS می‌خواند؛ HTML را اجرا نمی‌کند. سؤال و جواب از داخل ریشهٔ همان صفحه و آکاردئون‌های بومی استخراج می‌شوند. هر سؤال یک رکورد مستقل دارد؛ جست‌وجو روی متن کامل همهٔ رکوردها و سپس رتبه‌بندی عنوان/صفحه‌بندی انجام می‌شود. بنابراین جواب انتهای صفحه به‌دلیل کوتاه‌کردن ابتدای کل صفحه حذف نمی‌شود. متن پاسخ خروجی حداکثر ۲۴۰۰ نویسه و دارای پرچم truncated است.

کش عمومی WordPress حداکثر پنج دقیقه است؛ اثرانگشت نسخهٔ افزونه، محتوای صفحه و متای جاری Elementor، استفاده از نسخهٔ قبلی را پس از ویرایش قطع می‌کند. زمان post_modified به‌تنهایی کافی نیست. قبل از کش هم عمومی‌بودن و نبود رمز بررسی می‌شود. فقط کش همین قابلیت هنگام uninstall پاک می‌شود؛ هیچ پیام مشتری در این کش یا WordPress کپی نمی‌شود.

شناسه‌های دوستانهٔ موجود لینک مستقیم دارند. سؤال بومی تازه بدون نگاشت دوستانه هم خودکار وارد خواندن می‌شود؛ تا زمان ثبت شناسهٔ دوستانه در کد صفحه، مرجع آن خود صفحه است. تغییر ساختار HTML در ارتقای Elementor به آزمون adapter نیاز دارد؛ ساختار ناشناخته یا مبهم، خطای دسترسی است و به نبود پاسخ تعبیر نمی‌شود. مرز ۱ MiB/۱۰۰۰ رکورد برای جلوگیری از پردازش بی‌حد است؛ عبور از آن خطای صریح است و نتیجهٔ ناقص، کامل معرفی نمی‌شود.

مرجع‌های پاسخ فقط صفحه‌های عمومی مجاز سایت، شناسه‌های محدود FAQ و لینک ثابت رسمی تلگرام بخش طراحی هستند. مقصد خارجی تازه، خودکار مجاز نمی‌شود. این لینک‌ها تنها مسیر مراجعهٔ کاربرند؛ چت سفارش، تیکت یا پیام به پشتیبانی ارسال نمی‌کند. برای درخواست طراحی، امکان انجام، قیمت و زمان با پشتیبانی هماهنگ می‌شوند.

پاسخ‌های عمومیِ مرتبط می‌توانند راهنمای کوتاه و با بیان حدود داشته باشند. مقررات، قیمت، مشخصات محصول و وضعیت سفارش از دانش عمومی نتیجه گرفته نمی‌شوند. متن FAQ و خروجی ابزار همچنان دادهٔ نامطمئن‌اند و دستور یا مجوز ایجاد نمی‌کنند. noindex صفحه برای این منبعِ صریحاً مجاز مانع خواندن نیست و تغییر داده نشده است.

ترتیب انتشار: ابتدا افزونهٔ 0.8.0 و سپس Main 1.4.0. بازگشت برعکس است: ابتدا Main قبلی و سپس افزونهٔ قبلی. API v1، schemaها، چهار ابزار، گراف ۶۹نودی و قرارداد هزینه/تاریخچه محفوظ‌اند. PHP DOM برای FAQ لازم است؛ نبود آن قابلیت را با خطای کنترل‌شده می‌بندد. [سناریو و پذیرش](../specs/014-faq-knowledge/spec.md) و [شواهد](../specs/014-faq-knowledge/verification.md).

Main 1.4.1 اولویت FAQ را برای پرسش عملی خرید/حساب/ایمیل/تلفن روشن می‌کند؛ تعریف عمومی خریدار در قوانین، شاهد الزام ثبت‌نام نیست. پاسخ FAQ با حفظ معنای فنی و مرجع همان سؤال بازنویسی می‌شود؛ از اشارهٔ کلی به عرض برش، جهت تغییر شیار یا مقدار عددی ساخته نمی‌شود. این اصلاح تنها پرامپت است و ZIP افزونه همان 0.8.0 می‌ماند.

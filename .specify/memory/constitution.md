# GPante Support Chat Constitution

## Core Principles

### I. دامنهٔ اختیار و جداسازی تولید
کار فقط در مخزن انتخاب‌شده و دامنهٔ دستور جاری انجام شود. در مرحلهٔ اولیه ساخت محلی مجاز بود؛ درخواست بعدی کاربر، راه‌اندازی و ارتقای همین چت روی سایت را مجاز کرد. تغییرات به افزونه و سرویس چت محدود می‌مانند؛ قالب، افزونه‌های نامرتبط و سامانهٔ woo2 حفظ می‌شوند.

### II. منبع عمومی و پاسخ مستند
همهٔ کاتالوگ مجاز عمومی پوشش داده شود؛ سقف صفحه سقف کاتالوگ نیست. محصول خصوصی، مخفی یا رمزدار و لینک دانلود فروشی به مدل داده نشود. شکست خواندن نتیجهٔ خالی نیست.

### III. اعتماد و هزینه در سرور
شناسهٔ نشست و کلید در سرور کنترل شوند. سقف پروژه ۲ دلار در ماه UTC و آرشیو مدیر ۳۰ روز است؛ تاریخچهٔ کاربر را مدیر برای همه ۳/۷/۱۵/۳۰ روز تعیین می‌کند؛ state چت فقط در project_db باشد. مرورگر حق تعیین هویت معتبر یا رفع محدودیت ندارد.

### IV. سادگی و ارتقای سازگار
API بومی وردپرس و منابع موجود بازاستفاده شوند. نام گزینه‌ها، قرارداد نسخه‌دار و تنظیمات معتبر در ارتقا حفظ شوند؛ نصب تازه خاموش باشد. چارچوب و سرویس فرضی اضافه نشود.

### V. شواهد قابل اجرا
تغییر اعتماد، تنظیمات و ارتقا آزمون رفتاری دارد. آزمون مصنوعی، مرورگر واقعی، WordPress واقعی و تولید جدا گزارش شوند. دسترسی یا تست انجام‌نشده موفق معرفی نشود.

## محدودیت‌های محصول
رابط اولیه فارسی، راست‌به‌چپ و عمومی است. سفارش، حساب مشتری، پرداخت و دانلود اختصاصی در این نسخه نیستند. افزونه کد سمت سایت را نگه می‌دارد؛ مدل، بودجه و حافظه در n8n می‌مانند. نصب افزونه به‌تنهایی مجوز انتشار Main نیست.

## روش توسعه و بررسی
قابلیت جدید spec، plan و tasks دارد. capability، nonce، escaping، قرارداد API و مهاجرت تنظیمات بررسی شوند. ZIP نصب فقط runtime افزونه را شامل شود. کلید یا پشتیبان خصوصی وارد Git نشود. وضعیت مهارت همراه نتیجهٔ واقعی به‌روز شود.

## Governance
دستور جاری کاربر مقدم است. اصلاح اصول با دلیل و نسخهٔ معنایی ثبت شود. تغییر ناسازگار نیازمند مسیر مهاجرت و آزمون است. پیش از تحویل، تطابق نیازها و خروجی بررسی شود.

# GPante Support Chat — WordPress0.14.0

- اطلاعات محصولات متغیر، بازهٔ قیمت و نوع تحویل گزینه‌های عمومی و قابل خرید را نشان می‌دهد؛ یک گزینهٔ رایگان، کل محصول را رایگان نمی‌کند. اطلاعات نامعلوم و فایل‌های محافظت‌شده محفوظ‌اند.
- فیلتر ضخامت از اصطلاح‌های فعلی ووکامرس و مقادیر معادل استفاده می‌کند؛ جست‌وجوی عمومی CDR خانوادهٔ تأییدشده را پوشش می‌دهد و شروط صریح حفظ می‌شوند.
- تازه‌سازی پس‌زمینهٔ چت، فوکوس و موقعیت مطالعهٔ پیام‌های بدون تغییر را نگه می‌دارد.
- مدیریت، آمادگی مستقل پذیرش سؤال، هشدار اعتبار تعرفه و شمارش بی‌متن رد پذیرش را نمایش می‌دهد. شناسهٔ عمومی مقصد و نسخه/دورهای اجرا به گزارش محدود اضافه می‌شوند؛ دادهٔ مفقود نامشخص می‌ماند.
- تنظیمات موجود، ظاهر، سیاست نگهداری، بودجه و دفتر مالی حفظ می‌شوند. همراه Main1.9.0/Admin1.5.0 و migration افزایشی008 نصب شود؛ مهاجرت‌های قبلی دوباره اجرا نشوند.

تست‌های آفلاین، PHP، وردپرس/ووکامرس بومی، SQL ایزوله و مرورگر مصنوعی بدون تماس پولی مدل بررسی می‌شوند. [دامنه و ترتیب ارتقا](../../docs/assistant-reliability.md).

# GPante Support Chat 0.7.1

جست‌وجوی موضوع کوتاه مانند «اسب» اکنون محصولات دارای واژهٔ کامل در عنوان را پیش از تطبیق‌های داخل واژه و متن و سپس تاریخ انتشار قرار می‌دهد. قبلاً ترتیب relevance محصول عملاً به تاریخ تبدیل می‌شد و تطبیق «اسب» داخل «مناسب» محصول مرتبط را از صفحهٔ اول دور می‌کرد.

رتبه‌بندی روی همهٔ نامزدهای مجاز و پیش از صفحه‌بندی اعمال می‌شود؛ محصولی برای این اصلاح به‌صورت دستی ثبت یا ثابت نشده است. فیلترها، نامزدهای لفظی، ترتیب‌های صریح جدیدترین/پرفروش/ارزان‌ترین و ارتباط مقاله‌ها حفظ شده‌اند.

ارتقا: ZIP افزونه را جایگزین نسخهٔ قبلی کنید؛ حذف کامل نکنید. WordPress 6.6+، PHP 8.1+ و WooCommerce فعال نیازمندی‌های قبلی‌اند. تنظیمات، ظاهر، تاریخچه، API و schemaها حفظ می‌شوند؛ تغییر n8n، مدل، بودجه یا migration لازم نیست. برگشت با ZIP نسخهٔ 0.7.0 ممکن است.

اعتبارسنجی: آزمون بازگشت در WordPress/WooCommerce ایزوله پیش از اصلاح شکست خورد و پس از اصلاح موفق شد؛ عنوان فارسی/عربی، نیم‌فاصله، تطبیق داخل کلمه، نامزد محافظت‌شده، چند صفحه و ترتیب‌های صریح بررسی شدند. نامزد در اجرای صرفاً خواندنیِ کاتالوگ واقعی نیز محصول مرتبط را برای «اسب» و «طرح اسب» در صفحهٔ اول برگرداند. نتیجهٔ نصب و آزمون واقعی دستیار جداگانه در وضعیت پروژه ثبت می‌شود.

حدود: جست‌وجو همچنان لفظی است؛ ترتیب بهتر جای تشخیص معنایی ارتباط توسط دستیار را نمی‌گیرد. این تغییر آموزش مدل یا افزودن جست‌وجوی برداری نیست.

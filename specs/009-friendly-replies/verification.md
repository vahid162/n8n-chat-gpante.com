# بررسی نمایش خوانای پاسخ

۲۱ اکتبر ۲۰۲۶؛ افزونهٔ 0.5.0 از Release رسمی نصب و Main 1.2.3 منتشر و فعال است. بررسی نامزد و تولید در ادامه جدا ثبت شده‌اند.

۶۵ آزمون Node، آزمون تنظیمات/ظاهر/bridge/کاتالوگ PHP، پنج آزمون Python بسته/انتشار و WPCS با صفر خطا/هشدار گذشتند. renderer با دادهٔ معتبر و ناقص، URLهای ممنوع، HTML اجرایی، متن مختلط، pipe فراری، bold و بازگشت جدول بیش از ۲۰ ردیف به متن بررسی شد. بازیابی جدول/دکمه از تاریخچه، plain-text ماندن Markdown کاربر و آزمون‌های موجود چرخهٔ گفتگو/پیش‌نویس نیز پاس‌اند.

در Chrome با TLS معتبر و قالب واقعی سایت، فقط در همان مرورگر asset نامزد و پاسخ‌های مصنوعی جایگزین شدند؛ سایت و دیتابیس تغییر نکردند و هیچ پیام واقعی یا تماس مدل انجام نشد. دادهٔ مصنوعی شامل قیمت صفر، فرمت لاتین، متریال/ضخامت فارسی، جدول چهارستونی و HTML/لینک ممنوع بود.

| 1440×1000 | 390×650 | جدول داخل حباب، دکمه ۴۴ پیکسل، بدون overflow افقی |

caption، scope ستون/ردیف، wrapper جدول عریض با پیمایش صفحه‌کلید، لینک واقعی با target/rel قبلی، صفر violation محدود axe و صفر خطای runtime تأیید شدند. تصویرها و رسیدهای خصوصی خارج Git هستند. این بررسی‌ها جای آزمون Safari/iOS یا دستگاه فیزیکی نیستند.

نامزد Main با حفظ ۶۹ نود، graph، settings و Credentials فقط چهار literal پرامپت، یادداشت و توضیح نسخه را تغییر داد. activation، SDK strict و کامپایل Code روی n8n نصب‌شده بدون warning گذشت. سپس نسخهٔ نهایی منتشر و active=true، نسخهٔ فعال برابر draft و نودها/connections/settings برابر منبع بازخوانی شدند. هشدار قدیمی شلوغی canvas اجرایی نیست و تغییری نکرد.

## تولید

Release رسمی، tag ثابت، commit، SHA256 و هر ۱۲ فایل ZIP/نصب/منبع تطبیق داده شدند. runtime، هر دو کلید، enabled، schema، کل ظاهر، policy/revision، قالب و فهرست افزونه‌های فعال قبل/بعد برابرند. نسخهٔ تازه با WP-CLI/PHP 8.3 نصب، صفحهٔ native مدیر بدون افشای کلید render و فقط cache keyهای همین سایت پاک شدند. سرویس restart نشد؛ SQL یا budget تغییر نکرد. CI منبع و انتشار، شامل verify/archive-database/publish، موفق بود.

Chrome روی asset واقعاً نصب‌شده و TLS معتبر، همان سه اندازه، دکمهٔ ۴۴پیکسلی، جدول معنایی/عریض با حرکت واقعی ArrowLeft، HTML/لینک ممنوع، دسترسی کنترل‌ها و صفر violation محدود/خطای runtime را تأیید کرد. این سناریوها فقط در همان مرورگر mock بودند و صفر پیام واقعی داشتند.

یک نشست تازهٔ جدا، بدون mock، پرسش واقعی برای باکس آجیل DXF/MDF/۲٫۷ فرستاد. history/send/history همگی HTTP 200؛ یک جدول دو‌ستونی با هفت ردیف داده و یک دکمهٔ «مشاهدهٔ محصول» دریافت شد. لینک، قیمت و ویژگی‌های نمایش‌داده‌شده با خواندن تازهٔ کاتالوگ و شروط هم‌زمان تطبیق داشتند. هدف شش ردیفِ پرامپت در این پاسخ دقیقاً رعایت نشد؛ renderer تا ۲۰ ردیف معتبر را می‌پذیرد و قالب مدل ذاتاً تضمین شکلی نیست. هیچ داده‌ای برای کوتاه‌کردن خاموش حذف نشد.

زمان ارسال مرورگر حدود ۶٫۶ ثانیه و turn حدود ۴٫۹ ثانیه؛ دو تماس مدل با usage کامل و هزینهٔ محافظه‌کارانهٔ حدود ۰٫۰۰۳۸۸ دلار ثبت شد. پس از reload، همان جدول و URL دکمه و یک پیام کاربر بازگشتند. ورودی فوری، یک ارسال، درخواست‌های سریالی، عرض ۳۷۴پیکسل و عدم overflow و صفر خطای runtime/violation محدود تأیید شدند. مرورگرهای اختصاصی بسته شدند. هر ۲۴ workflow قبلی، policy و runtime مالی ثابت‌اند؛ lease فعال پایان صفر بود.

Safari/iOS، دستگاه فیزیکی و بار گسترده آزموده نشده‌اند. نصب قدیمی‌تر جدول‌های تازه را به‌شکل متن Markdown می‌خواند؛ rollback نباید تاریخچه یا schema را حذف کند. رنگ‌های مدیر، اندازهٔ پنجره و سیاست نگهداری مستقل از این قابلیت‌اند.

# وضعیت خوانای اتصال چت

درخواست: نمایش روشن اتصال، آمادگی و انتظار پاسخ با انیمیشن و تأیید بصری در ناحیهٔ وضعیت موجود. افزونه 0.6.1، مهارت 0.8.1؛ Main 1.3.0 و schemaها ثابت می‌مانند.

- متن دو سطحی با عنوان و توضیح، آیکون تزئینی aria-hidden و همان live region polite موجود.
- حالت‌های connecting، refreshing، waiting، clearing، ready، error، offline و notice از نتیجهٔ واقعی عملیات می‌آیند؛ خطای متن پیام، قطع ارتباط نامیده نمی‌شود.
- آمادگی پس از پاسخ معتبر chat API شامل سیاست و نتیجهٔ معتبر است؛ پاسخ appearance یا navigator.onLine=true کافی نیست. این بررسیِ آمادگیِ سرویس HTTP است و سلامت پیوستهٔ provider را تضمین نمی‌کند.
- نشان سبز/تأیید پس از موفقیت و spinner هنگام درخواست؛ اطلاعات تنها با رنگ منتقل نشوند. prefers-reduced-motion حرکت را خاموش کند.
- نوشتن فوری، یک ارسال منتظر، کوکی امضاشده، retry صریح، draft، سیاست clear و خطا/زمان انتظار قبلی حفظ شوند. آنلاین‌شدن، فقط یک history مشترک را بررسی کند؛ در ارسال فعال درخواست دیگری آغاز نشود.
- ابعاد panel، ظاهر مدیر، قراردادها، n8n، SQL، بودجه و مدل تغییر نکنند؛ embed از منبع canonical بازسازی شود.

ارتقا فقط همین افزونه از ZIP رسمی است، با حفظ تمام تنظیمات و پشتیبان محدود خارج webroot. rollback با ZIP قبلی و بدون تغییر داده/تنظیمات انجام می‌شود. آزمون مدل برای این تغییر لازم نیست؛ درخواست مصنوعی مرورگر باید پیش از رسیدن به سرور intercept شود.

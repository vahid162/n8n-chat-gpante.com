# وضعیت جاری پروژهٔ چت جی‌پانته

ثبت: ۱۹ اکتبر ۲۰۲۶. مخزن مرجع: [n8n-chat-gpante.com](https://github.com/vahid162/n8n-chat-gpante.com). وضعیت زنده و مجوز درخواست فعلی بر این ثبت تاریخی مقدم‌اند.

## تصمیم و نتیجهٔ این مرحله

کاربر ساخت اولین ورک‌فلو و ثبت قانون نام‌گذاری در مهارت را خواست و اتصال DeepSeek موجود را انتخاب کرد. هدف همچنان محصول کامل با پوشش کل کاتالوگ مجاز عمومی است؛ محدودیت ۳۰/۵۰ محصول یا پایلوت انتخابی وجود ندارد. ساخت این نسخه مجوز انتشار عمومی، نصب ویجت، دسترسی به سفارش‌ها یا تغییر woo2 نیست.

مهارت نسخهٔ ۰٫۲٫۰ است. منبع نصب‌شده به همین checkout پیوند دارد؛ بستهٔ قابل حمل نسخهٔ مستقل است و با Git خودکار همگام نمی‌شود. مهارت قدیمی woo2 تغییر نکرده و وابستگی این پروژه نیست.

## رفتار پیاده‌سازی‌شده

- سه ابزار محدود: جست‌وجوی محصول با فیلترهای AND، خواندن مشخصات/قیمت فعلی محصول، و خواندن نوشته‌های عمومی/دو راهنمای واقعی سایت.
- مقصد ثابت، پارامتر و خروجی allowlist؛ مدل SQL، URL یا کد آزاد نمی‌دهد. ابزارهای مدیریت، انتشار، فایل پولی و اطلاعات مشتری متصل نیستند.
- تطبیق ویژگی با term دقیق WooCommerce؛ یکسان‌سازی اعداد و حروف فارسی/عربی و ضخامت/فرمت. term ترکیبی متریال الزاماً معادل term ساده نیست.
- جست‌وجو در Store API با `catalog_visibility=search` و صفحهٔ پنج‌تایی؛ شمارش و وضعیت صفحه‌بندی حفظ می‌شوند. جزئیات هم از همین فهرست با include شناسه خوانده می‌شود؛ مسیر جزئیات بدون کنترل visibility وجود ندارد.
- ورودی متن حداکثر ۴۰۰۰ نویسه و نشست ۱۶ تا ۱۲۸ نویسه؛ حافظه با کلید نشست جدا و پنجرهٔ ۶ نوبت. شناسهٔ نشست احراز هویت نیست.
- پیش‌فرض مهندسی پیش‌نویس: ۱۰ درخواست پذیرفته‌شده/نشست/۶۰ ثانیه و ۲۰۰۰ درخواست سراسری/۲۴ ساعت، چهار دور Agent و ۱۵۰ ثانیه اجرا. این اعداد تصویب بودجهٔ تولید یا سقف قطعی هزینه نیستند.
- تاریخچهٔ بیش از هفت روز در درخواست بعدی پاک می‌شود؛ پاک‌سازی مستقل از ترافیک و سیاست نهایی نگهداری هنوز لازم‌اند.
- تنظیمات ذخیرهٔ محتوای اجرای موفق/ناموفق/دستی خاموش‌اند. حافظهٔ گفتگو در دیتابیس کاربردی جداست.

## شواهد و حدود اعتبارسنجی

در این مرحله مدل فراخوانی نشد و مکالمهٔ مشتری وارد آزمون نشد:

- ۱۶ آزمون Node موفق: اعتبار ورودی، مرز نشست، محدودیت پیام، خطای بودجه، پاک‌سازی پاسخ، فیلترهای ترکیبی، صفحه‌بندی، قیمت صفر/واحد خرد، خطای API/429 و خروجی عمومی.
- اعتبارسنج نصب‌شدهٔ n8n و SDK strict برای Main و هر سه ابزار داخلی موفق بود؛ هشدار صفر. این بررسی روی کپی خصوصیِ دارای اتصال انجام شد؛ فایل عمومی عمداً Credentials ندارد.
- آزمون مصنوعی CLI با ۲۱ نود، وضعیت `success` داشت: مسیر اعتبارسنجی/رزرو PostgreSQL، جایگزین مصنوعی مدل و هر سه زنجیرهٔ واقعی Code → HTTP → پاک‌سازی → assertion. این آزمون جای tool-calling یا پاسخ واقعی DeepSeek را نمی‌گیرد.
- ناسازگاری prototype اشیای بین realmهای Code و نیاز JSON Query به رشته در HTTP Request 4.4 با اجرای واقعی پیدا و اصلاح شدند. آزمون بازگشت برای realm جدا وجود دارد.
- آزمون SQL: نشست نامعتبر، سقف نشست/جهانی، بازنشانی پنجره، حذف تاریخچهٔ قدیمی و نساختن نشست تازه پس از سقف جهانی. تمام fixtureها rollback شدند.
- کتابخانهٔ واقعی حافظهٔ native PostgreSQL با پیام مصنوعی آزموده شد: نمونهٔ تازه پیام همان نشست را بازیابی کرد و نشست دیگر خالی بود؛ دادهٔ آزمون پاک شد. این بررسی جای مکالمهٔ چندنوبتی Agent را نمی‌گیرد.
- ورک‌فلوی مصنوعی Validation پس از آزمون به‌صورت رسمی آرشیو شد و غیرفعال است. فایل موقتِ رمز خام اتصال جدید از میزبان و کانتینر حذف شد.
- نقش دیتابیس چت هنگام ایجاد به هیچ جدولِ خارج از schema خودش دسترسی SELECT/INSERT/UPDATE/DELETE نداشت.
- اثرانگشت تعریف، نسخه‌ها و وضعیت ۱۵ ورک‌فلوی قبلی با پیش از تغییر برابر بود. سرویس مشترک restart نشد.

بازبینی `ce-code-review` با ۱۱ لنز کامل شد؛ تنها یافتهٔ P2، عبور لینک Markdown با فاصله/ارجاع، اصلاح شد. آزمون بازگشت ابتدا شکست خورد و سپس موفق شد؛ ۱۰ بررسی مستقل با CommonMark، حذف مقصدهای بیرونی و تصاویر و حفظ لینک صحیح سایت را تأیید کردند. این بازبینی شاهد آمادگی انتشار عمومی نیست.

جزئیات فنی و روش بازسازی در [workflow-v1.md](workflow-v1.md) است. اعتبارسنج رسمی مهارت موفق بود. کد و مهارت نسخهٔ اول در شاخهٔ `feat/support-chat-v1` نگهداری می‌شوند؛ پیش از کار با checkout دیگری، وضعیت شاخه و ادغام آن در GitHub بررسی شود. بستهٔ قابل حمل نسخهٔ ۰٫۲٫۰ باید با همین منبع نهایی برابر باشد؛ نصب در حساب ابری انجام نشده است.

## شواهد منبع عمومی

مشاهدهٔ ۱۹ اکتبر ۲۰۲۶، به معنی عدد ثابت آینده یا crawl تک‌تک محصولات نیست:

- `wc/store/v1/products` با `catalog_visibility=search` و `visible` هر دو ۱۰۸۱ محصول گزارش کردند.
- جست‌وجوی «باکس آجیل» با فرمت DXF، ضخامت ۲٫۷ و MDF، ۷ نتیجه در دو صفحه داد؛ هر دو صفحه خوانده و عدم تکرار شناسه بررسی شد.
- جزئیات محصول عمومی ۴۹۳۰۴ موفق بود؛ قیمت از `prices` و واحد خرد خوانده می‌شود.
- ابزار راهنما صفحات عمومی قوانین ۴۷۵۲ و تماس ۴۷۴۳ را خواند. نوشته‌های عمومی از `wp/v2/posts` با status=publish خوانده می‌شوند.
- نبود نتیجه، شکست ارتباط، پاسخ ناقص و عدم انطباق ویژگی‌ها در قرارداد ابزار وضعیت‌های جدا دارند.

این شواهد کامل‌بودن جست‌وجوی معنایی، سیاست همهٔ visibilityها/رمزدارها یا قابلیت یافتن ارزان‌ترین محصول کل کاتالوگ را ثابت نمی‌کنند.

## زیرساخت و دسترسی

n8n نصب‌شده نسخهٔ ۲٫۴۳٫۷، یک instance با regular mode و task runner؛ PostgreSQL کاربردی موجود برای حافظه استفاده شد. SSH/Docker و CLI رسمی مسیر واقعی این مرحله بودند؛ MCP اختصاصی n8n یا API احراز هویت‌شده تأیید نشده است. کلید API از دیتابیس خوانده نشد. اطلاعات اتصال و export کامل خارج از مخزن عمومی نگه داشته می‌شوند.

## کار بعدیِ باقی‌مانده

1. آزمون واقعی DeepSeek برای ابزارخوانی، پاسخ فارسی و ادامهٔ چندنوبتی و جداسازی نشست‌ها؛ اندازه‌گیری تاخیر، مصرف و هم‌زمانی.
2. نهایی‌کردن سیاست محصولات واجد کشف عمومی، از جمله catalog-only/پنهان/رمزدار و تغییر/حذف؛ بررسی مترادف‌ها و termهای ترکیبی با پرسش‌های واقعی کاربران.
3. تأیید سقف مصرف و نگهداری/حذف تاریخچه؛ کنترل سوءاستفاده با هویت/IP قابل اعتماد و بررسی پراکسی پیش از مسیر عمومی.
4. ساخت و آزمون ویجت فارسی/RTL روی موبایل و دسکتاپ؛ انتشار فقط پس از آمادگی و مجوز مربوط.
5. مراحل بعدی محصول: حساب مشتری، سفارش/دانلود و ارجاع انسانی با احراز هویت و دامنهٔ جدا.

هیچ‌یک از این کارهای باز، به معنی محدودکردن محصول به یک کاتالوگ نمایشی نیست. نسخهٔ حاضر پیش‌نویس پایهٔ محصول است و آمادهٔ انتشار عمومی اعلام نشده است.

# GPante Support Chat 0.8.1

جست‌وجوی FAQ عبارت‌های «موبایل»، «شماره همراه»، «جا نمیره» و صورت‌های رایج مشکل بازشدن فایل را بهتر پیدا می‌کند. عبارت کامل و واژهٔ کامل عنوان اولویت دارند؛ نسخه، جنس و سایر شروط صریح حذف نمی‌شوند.

هم‌معنی‌ها فقط در منبع FAQ اعمال می‌شوند. جست‌وجوی محصول/مقاله، API v1، تنظیمات اتصال و ظاهر، تاریخچه و آرشیو حفظ می‌شوند. افزونه پیش از Main 1.5.0 نصب شود؛ برگشت نسخه به ترتیب معکوس است.

نیازمندی‌ها همان WordPress 6.6+، PHP 8.1+ و WooCommerce هستند. ارتقا با ZIP رسمی و جایگزینی نسخهٔ موجود انجام شود؛ حذف کامل افزونه لازم نیست.

آزمون parser/callback و وردپرس جداگانه، هم‌معنی‌ها، عبارت محاوره‌ای، شروط نسخه/جنس، کش، محدودیت منبع و رتبه‌بندی را پوشش می‌دهند. این تغییر تضمین صحت معنایی همهٔ پاسخ‌های مدل نیست؛ گزارش بررسی همان نسخه در مخزن ثبت می‌شود.

# شواهد نسخهٔ 0.6.2

۲۱ اکتبر ۲۰۲۶؛ این بخش پیش از انتشار، فقط نامزد مرورگری را توصیف می‌کند. نصب تولید پس از تطبیق Release جداگانه ثبت می‌شود.

- ۸۰ آزمون Node موفق‌اند؛ سه رگرسیون اصلی پیش از اصلاح قرمز بودند: Online مستقل از انتظار پاسخ، history پیش از ارسال نامعلوم و rate limit بدون قطع اتصال. موارد اتصال مجددِ پاک‌کردن، انقضای متن پس از refresh ناموفق، guard تکرار، سیاست، focus و draft نیز بررسی شدند.
- PHP settings/appearance/bridge و ۲۴ بررسی query موفق‌اند؛ WPCS بدون خطا/هشدار است. دو کد ثابت بودجه/بازبینی سرویس بدون متن خصوصی backend آزموده شدند.
- نامزد روی قالب و ظاهر واقعی gpante.com در Chromium و Firefox، هرکدام در چهار اندازه بررسی شد: ۱۴۴۰×۱۰۰۰→۳۹۰×۶۵۰، ۳۹۰×۸۴۴→۳۷۴×۶۵۰، ۳۲۰×۵۶۸→۳۰۴×۴۸۰ و ۸۴۴×۳۹۰→۳۹۰×۳۶۶. سربرگ عادی حدود ۸۴٫۲ و کوتاه حدود ۶۶٫۲ پیکسل ماند؛ فضای پیام در کنترل‌های یکسان افزایش یافت، overflow صفر و دکمهٔ بستن ۴۴ پیکسل است.
- اتصال اولیه، سه‌نقطه، reduced-motion، خطای ارسال، شکست refresh با حفظ پیام، بازیابی پاسخ ذخیره‌شده، retry صریح، rate limit، offline/online و عنوان بلند بررسی شدند. همهٔ chat requestها پیش از سرور intercept شدند؛ پیام واقعی، تماس مدل و خطای runtime صفر بود. تصویر Firefox نیز دستی بازبینی شد.
- پنج آزمون Python بسته/انتشار و ساخت قطعی ۱۲ فایل runtime موفق‌اند؛ embed از همان template/assets بازسازی شد.
- ابزار قابل تکرار: `tests/chat-status-browser.py`؛ داده/تصویر آزمون و شناسه‌های استقرار خصوصی‌اند و در مخزن ثبت نمی‌شوند.

Safari/iOS و دستگاه فیزیکی آزمایش نشده‌اند. این تغییر idempotency منطقی یا ذخیرهٔ پیش‌نویس بین صفحات اضافه نمی‌کند؛ خواندن تاریخچه تضمین پایان پردازش همهٔ درخواست‌های قبلی نیست.

# تنظیم و چرخهٔ عمر

گزینهٔ `gpante_support_runtime`، nonautoload و بدون REST exposure:
- schema_version: عدد 1؛ نسخهٔ بالاتر حفظ و اجرای ناسازگار متوقف شود.
- enabled: bool واقعی؛ پیش‌فرض false.
- backend_url: نشانی ثابت فعلی n8n؛ قابل تنظیم به مقصد دلخواه نیست.
- shared_key: رشتهٔ ASCII بدون فاصله، 32..256 نویسه؛ پیش‌فرض خالی؛ در فرم value ندارد.

مهاجرت از گزینهٔ پیشین بدون schema، مقادیر معتبر را حفظ و schema را اضافه می‌کند.
ذخیرهٔ خالی کلید را حفظ می‌کند؛ ورودی نامعتبر گزینهٔ پیشین را حفظ و پیام عمومی می‌دهد.
غیرفعال/فعال‌کردن داده را حفظ می‌کند؛ uninstall فقط همین option را حذف می‌کند.
هیچ تاریخچه، IP خام، مشتری، سفارش یا ledger در وردپرس ساخته نمی‌شود.

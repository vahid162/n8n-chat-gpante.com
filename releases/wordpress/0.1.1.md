اصلاح سازگار کاتالوگ **GPante Support Chat 0.1.1**.

ویژگی‌ها، مقادیر ویژگی و تصاویر در Schema بومی WooCommerce می‌توانند از نوع `stdClass` باشند. افزونه اکنون این ساختارها را پیش از انتخاب فیلدهای عمومی به آرایه تبدیل می‌کند؛ خطای ۵۰۳ ناشی از این تفاوت نوع رفع می‌شود. قیمت صفر و محدودیت فیلدهای خروجی حفظ شده‌اند.

آزمون رگرسیون هر دو شکل آرایه و شیء را پوشش می‌دهد و حذف فیلدهای خارج از فهرست عمومی را بررسی می‌کند.

فایل `gpante-support-chat-wordpress-0.1.1.zip` را از Assets دانلود و در بخش بارگذاری افزونهٔ وردپرس، جایگزینی نسخهٔ موجود را انتخاب کنید. تنظیمات و کلید اتصال حفظ می‌شوند؛ افزونه را پیش از ارتقا حذف کامل نکنید. بسته‌های Source code برای نصب وردپرس نیستند.

فایل `SHA256SUMS` برای بررسی صحت ZIP همراه انتشار است. شرایط لازم همچنان WordPress 6.6+، PHP 8.1+ و WooCommerce فعال است. دریافت و نصب نسخه‌های جدید با ZIP انجام می‌شود؛ به‌روزرسانی خودکار از GitHub وجود ندارد.

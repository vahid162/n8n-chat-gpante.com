نسخهٔ **GPante Support Chat 0.2.0** امکان مرور گفتگوها و پاسخ‌های دستیار را در «چت پانته ← گفتگوها» اضافه می‌کند.

- آرشیو مدیریتی مستقل تا ۳۰ روز از زمان پرسش، با صفحه‌بندی، فیلتر و نمایش وضعیت/خطا.
- تعیین سراسری تاریخچهٔ قابل مشاهدهٔ کاربران: ۳، ۷، ۱۵ یا ۳۰ روز.
- روشن/خاموش‌کردن پاک‌کردن کاربر؛ این عمل دسترسی کاربر و زمینهٔ مدل را می‌بندد و آرشیو مدیر را حفظ می‌کند. متن رابط این رفتار را توضیح می‌دهد.
- ثبت پرسش پذیرفته‌شده، پاسخ نهایی و خطای محدود؛ کلید مدیریت مستقل و بدون کپی پیام‌ها در دیتابیس وردپرس.

**ارتقا:** ابتدا migration 003 و workflowهای سازگار در سرویس پروژه آماده شوند؛ سپس ZIP را با گزینهٔ جایگزینی نصب کنید. افزونه را حذف کامل نکنید؛ کلید قبلی و فعال‌بودن حفظ می‌شوند. کلید مدیریت جداگانه در تنظیمات اتصال لازم است. کلاینت‌های قدیمی باید صفحه را تازه کنند. بازگشت به منطق قدیمی حذف فیزیکی با آرشیو جدید سازگار نیست. [راهنمای آرشیو و ارتقا](https://github.com/vahid162/n8n-chat-gpante.com/blob/main/docs/conversation-archive.md).

Asset نصب `gpante-support-chat-wordpress-0.2.0.zip` و `SHA256SUMS` هستند؛ Source code ZIP بستهٔ وردپرس نیست. نیازمندی: WordPress 6.6+، PHP 8.1+ و WooCommerce فعال. updater خودکار GitHub اضافه نشده است.

آزمون‌های Node/PHP، migration و retention روی PostgreSQL جدا، فرم‌های واقعی WordPress و Chrome در دسکتاپ/موبایل انجام شدند. Safari/iOS، multisite و آزمون بار گسترده پوشش داده نشده‌اند. حذف فیزیکی پیام منقضی تا نوبت ساعتی بعد انجام می‌شود؛ خواندن در مرز نگهداری بسته است.

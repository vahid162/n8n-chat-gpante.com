# GPante Support Chat 0.7.0

هر پیشنهاد و بخش مستقل پاسخ اکنون حباب جدا با فاصلهٔ روشن دارد. جدول مشخصات به فهرست خطی تبدیل می‌شود؛ تاریخچهٔ قبلی نیز همین نمایش تازه را می‌گیرد، بدون تغییر متن آرشیو.

عکس کوچک محصول در سمت راست عنوان و توضیح نمایش داده می‌شود. وردپرس تصویر شاخص همان محصول عمومی را به‌صورت metadata محدود می‌فرستد؛ مدل تصویر تعیین نمی‌کند. عکس ناموجود/خراب پنهان و متن/دکمه قابل استفاده می‌مانند. رنگ‌ها، ابعاد پنجره و وضعیت اتصال حفظ می‌شوند.

ارتقا: ZIP افزونه را جایگزین نسخهٔ قبلی کنید؛ حذف کامل نکنید. تنظیمات، سیاست، تاریخچه، مدل و بودجه حفظ می‌شوند؛ migration، endpoint یا تغییر n8n لازم نیست. WordPress 6.6+، PHP 8.1+ و WooCommerce فعال نیازمندی‌های قبلی‌اند. برگشت به 0.6.2 با ZIP قبلی و بدون حذف تنظیمات ممکن است.

اعتبارسنجی شامل ۸۵ تست Node، تست‌های PHP برای bridge/eligibility تصویر/تنظیمات/۲۴ query، WPCS و پنج تست بسته/انتشار، تصاویر واقعی در WordPress/PHP 8.3 و نامزد Chromium/Firefox در چهار اندازه، خطای عکس، Tab و reload است. chat مرورگر مصنوعی و پیش از سرور intercept شده؛ تماس مدل لازم نبود. شواهد نصب جدا در گزارش پروژه ثبت می‌شوند.

حدود: تصویر فقط برای لینک canonical محصول عمومی و raster محلی معتبر است؛ نبود یا ابهام عکس متن را حذف نمی‌کند. Safari/دستگاه فیزیکی بررسی نشده‌اند.

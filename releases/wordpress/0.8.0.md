# GPante Support Chat 0.8.0

دستیار می‌تواند سؤال‌وجواب مرتبط را از همان صفحهٔ FAQ رسمی Elementor بخواند و لینک مستقیم پاسخ را ارائه کند. ویرایش یا افزودن سؤال به بازسازی دستی فهرست نیاز ندارد؛ سؤال تازهٔ بدون شناسهٔ دوستانه به خود صفحه لینک می‌گیرد. کش عمومی کوتاه و وابسته به محتوای جاری Elementor است.

لینک رسمی پشتیبانی و تلگرام بخش طراحی به‌صورت دکمهٔ امن نمایش داده می‌شود؛ دستیار سفارش طراحی یا پیام به تیم ارسال نمی‌کند. پذیرش لینک خارجی فقط به مقصد رسمیِ ثابت محدود است.

ابتدا این افزونه و سپس Main 1.4.0 منتشر شود. بسته ۱۳ فایل runtime دارد و به WordPress 6.6+، PHP 8.1+، افزونهٔ DOM برای FAQ و WooCommerce فعال متکی است. تنظیمات و API v1 و schemaها حفظ می‌شوند؛ migration یا تغییر بودجه/تاریخچه لازم نیست. برای rollback ابتدا Main قبلی، سپس ZIP افزونهٔ 0.7.1 بازگردد؛ افزونه حذف کامل نشود.

شواهد و حدود در [گزارش FAQ](../../specs/014-faq-knowledge/verification.md) ثبت می‌شوند. بررسی صفحهٔ واقعی در Chromium/Firefox و آزمون استخراج در WordPress انجام شده است؛ نصب و آزمون واقعی دستیار پس از انتشار جداگانه ثبت می‌شوند. Safari/دستگاه فیزیکی بررسی نشده‌اند.

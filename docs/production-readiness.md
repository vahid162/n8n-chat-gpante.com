# بررسی راه‌اندازی روی سایت واقعی

تاریخ بررسی: ۲۰ اکتبر ۲۰۲۶. افزونهٔ **GPante Support Chat 0.1.1** از بستهٔ رسمی GitHub Releases نصب و نمایش عمومی آن روی gpante.com روشن شد. این گزارش شاهد بررسی همان زمان است؛ وضعیت زنده و تعداد محصولات ممکن است تغییر کنند.

## محیط بررسی‌شده

| جزء | نسخه |
| --- | --- |
| WordPress | 7.1.3 |
| WooCommerce | 11.2.1 |
| WoodMart | 8.6.4 با قالب فرزند فعال |
| PHP سایت | 8.3.32 |
| مرورگر آزمون | Chrome 155 |

## نتیجه‌ها

| بخش | نتیجهٔ مشاهده‌شده |
| --- | --- |
| بسته | ZIP رسمی، SHA256 و هر ۱۰ فایل runtime تطبیق داشتند؛ تنظیمات در ارتقا حفظ شدند |
| کاتالوگ | ۱۰۸۱ محصول عمومی در ۲۱۷ صفحه، بدون تکرار/جاافتادگی نسبت به query عمومی منبع؛ شکل خروجی همهٔ صفحات با ابزار سازگار بود |
| مرز صفحه‌بندی | صفحهٔ آخر یک محصول داشت؛ صفحهٔ بعد خالی بود و شمار کل را حفظ کرد |
| فیلتر و قیمت | فرمت DXF، ضخامت ۲٫۷ و MDF هم‌زمان اعمال شدند؛ ترتیب قیمت از منبع بود و محصول رایگان، صفر تومان ماند |
| راهنما | هر دو صفحهٔ عمومی مجاز از مسیر راهنما خوانده شدند |
| اتصال واقعی | سایت به backend احرازشده متصل شد؛ پرسش محصول پاسخ با قیمت، ویژگی و لینک منطبق با منبع گرفت |
| مرورگر | ارسال واقعی، بازیابی پس از reload، جداسازی دو بازدیدکننده و حذف ماندگار تاریخچه موفق بودند |
| کوکی | HTTPS، Secure، HttpOnly، SameSite=Strict و محدودبودن کوکی به میزبان بررسی شدند |
| خطای ارتباط | قطع ارتباط فقط در مرورگر آزمایش، خطای قابل مشاهده داد؛ تلاش مجدد صریح، بارگذاری گفتگو را برگرداند |
| اندازهٔ صفحه | ۱۴۴۰×۱۰۰۰، ۳۹۰×۸۴۴ و ۸۴۴×۳۹۰؛ پنجره داخل صفحه و کنترل‌ها با اسکرول قابل دسترسی بودند |
| خطای JavaScript | در سناریوهای ثبت‌شدهٔ مرورگر، خطای runtime مشاهده نشد |
| نگهداری | اجرای طبیعی پاک‌سازی زمان‌بندی‌شده بررسی شد؛ جزئیات اجرا و رسیدهای عملیاتی خصوصی نگهداری می‌شوند |

خطای واقعی کاتالوگ در 0.1.0 ناشی از رکوردهای ویژگی، term و تصویرِ `stdClass` در Schema بومی WooCommerce بود. نسخهٔ 0.1.1 آن‌ها را پیش از انتخاب فیلدهای عمومی تبدیل می‌کند؛ فهرست مجاز خروجی و شرایط عمومی‌بودن تغییر نکرده‌اند.

HTTPS، مسیر بدون cache چت، هویت شبکهٔ سروری و timeoutهای مسیر بررسی شدند. درخواست‌های طولانی چت در پردازش جدا از صفحات معمول سایت اجرا می‌شوند. تنظیمات میزبانی، بخشی از ZIP وردپرس نیستند؛ پس از تغییر PHP، وب‌سرور، پراکسی یا تنظیمات پنل باید دوباره بررسی شوند. تغییرات عملیاتی با پشتیبان خصوصی و اعتبارسنجی تنظیمات انجام شدند.

## بررسی هر ارتقا

1. نسخهٔ نصب‌شده و ZIP انتشار مقصد را تطبیق دهید؛ پشتیبان فایل‌های افزونه و تنظیم خصوصی را خارج از وب بگیرید.
2. ZIP جدید را جایگزین کنید؛ uninstall نکنید. کلید و انتخاب نمایش عمومی باید حفظ شوند.
3. کاتالوگ، قیمت و فیلتر ترکیبی، ارسال، reload، نشست جدا و حذف تاریخچه را بررسی کنید؛ تماس مدل را محدود نگه دارید.
4. پاسخ چت نباید cache عمومی یا کلید خصوصی داشته باشد. در تغییر نمایش، فقط cache همان سایت را پاک کنید.
5. بودجه، تسویهٔ تماس‌ها و اجرای نگهداری را از سرویس واقعی بخوانید؛ رسید کامل و دادهٔ گفتگو وارد مخزن عمومی نشوند.

## حدود نتیجه

این بررسی، آزمون بار گسترده یا تضمین سرعت نیست. Safari/iOS واقعی، multisite و همهٔ نسخه‌های حداقل اعلام‌شده بررسی نشده‌اند. مدل ممکن است اشتباه کند؛ پاسخ‌های آینده باید همچنان با منبع سنجیده شوند. قابلیت حساب، سفارش و دانلود اختصاصی مشتری در این نسخه وجود ندارد.

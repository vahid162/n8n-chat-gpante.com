دستیار فارسی عمومی جی‌پانته، با واسط امن سمت سرور و اتصال به سرویس n8n موجود.

== Description ==
رابط راست‌به‌چپ، ارسال و ادامهٔ گفتگو، نمایش خطا و تلاش دوباره، حذف تاریخچه و کاتالوگ عمومی WooCommerce.
نصب اولیه خاموش است. از Settings > چت جی‌پانته، کلید خصوصی اتصال را وارد و نمایش عمومی را روشن کنید.
کلید در مرورگر بازنمایش داده نمی‌شود. ذخیرهٔ ورودی خالی، کلید قبلی را حفظ می‌کند.

مدل، حافظه و سقف هزینه در n8n و دیتابیس پروژه می‌مانند. افزونه به حساب، سفارش یا دانلود اختصاصی مشتری دسترسی ندارد.
وردپرس باید HTTPS داشته باشد. WooCommerce و قالب باید از hookهای استاندارد wp_head و wp_footer پشتیبانی کنند.

= سرویس بیرونی و حریم خصوصی =
پس از روشن‌کردن توسط مدیر، با بازکردن چت یا ارسال/حذف پیام، سرور سایت به نشانی ثابت
https://n8n.gpantex.com/webhook/gpante-ai-support-v1
درخواست می‌فرستد. متن پیام، شناسهٔ امضاشدهٔ نشست و شناسهٔ HMAC از IP سرور ارسال می‌شوند؛ IP خام و کلید اتصال به مرورگر داده نمی‌شوند.
سرویس موجود از مدل DeepSeek استفاده می‌کند. آرشیو مدیر تا ۳۰ روز از زمان اصلی پرسش نگهداری می‌شود. مدیر مدت نمایش کاربران را ۳، ۷، ۱۵ یا ۳۰ روز تعیین می‌کند؛ پاک‌کردن کاربر فقط دسترسی و زمینهٔ مدل را می‌بندد و آرشیو مدیر را حذف نمی‌کند.
کوکی __Host-gpante_support با Secure، HttpOnly و SameSite=Strict، حداکثر ۳۰ روز معتبر است.
افزونه اطلاعات گفتگو را در دیتابیس وردپرس ذخیره نمی‌کند. اپراتور سایت مسئول اطلاع‌رسانی سیاست حریم خصوصی و آماده‌بودن سرویس است.
قرارداد و سیاست عملیاتی پروژه: https://github.com/vahid162/n8n-chat-gpante.com

= کاتالوگ =
GET /wp-json/gpante-support/v1/products و /knowledge، فقط داده‌های عمومی مجاز را عرضه می‌کنند؛ این endpointها مستقل از کلید روشن‌کردن چت‌اند.
پوشش تولید سقف تعداد محصول ندارد. اندازهٔ صفحهٔ محصول پنج و راهنما سه است؛ صفحه‌بندی و شمار کل حفظ می‌شوند.

== Installation ==
1. ZIP مستقل gpante-support-chat-wordpress-X.Y.Z.zip را در Plugins > Add New > Upload Plugin بارگذاری کنید.
2. WooCommerce باید فعال باشد. سپس GPante Support Chat را فعال کنید؛ چت همچنان خاموش است.
3. اتصال n8n، کلید اختصاصی، HTTPS، پراکسی/IP، timeout و استثنای cache مسیر REST را آماده کنید.
4. Settings > چت جی‌پانته را باز، کلید را از مسیر خصوصی وارد و نمایش عمومی را روشن کنید.
5. اگر embed دستی قبلی استفاده می‌شود، آن را پیش از نمایش خودکار حذف کنید؛ دو روش را با هم درج نکنید.

== Frequently Asked Questions ==
= آیا نیاز به ویرایش قالب یا نصب وابستگی تازه دارد؟ =
خیر؛ به API بومی WordPress و WooCommerce موجود متکی است. سرویس مدل موجود باید آماده باشد.

= ارتقا تنظیمات را پاک می‌کند؟ =
خیر. schema_version مستقل از نسخهٔ افزونه است؛ گزینهٔ gpante_support_runtime و مقدار معتبر آن حفظ می‌شوند.
غیرفعال‌کردن داده را حذف نمی‌کند. حذف کامل افزونه فقط گزینه‌های اتصال و ظاهر خودش را پاک می‌کند؛ تاریخچهٔ بیرونی تابع سرویس n8n است.
به نسخهٔ قدیمی‌تر دارای schema ناسازگار برنگردید؛ نسخهٔ ناشناخته اتصال را خاموش می‌کند و داده را حفظ می‌کند.

= آیا به‌روزرسانی خودکار از GitHub دارد؟ =
خیر. Update URI از اشتباه با افزونهٔ هم‌نام جلوگیری می‌کند؛ ارتقا فعلاً با ZIP جدید وردپرس انجام می‌شود.

== Appearance ==
از پیشخوان، «چت پانته ← ظاهر» را باز کنید. عنوان، زیرعنوان، دکمهٔ بازکردن، خوشامدگویی، عنوان و راهنمای کادر پرسش و دکمه‌های ارسال/گفتگوی تازه قابل تغییرند.
هشت رنگ اصلی، پنجره، متن، بخش پیام‌ها و حباب‌ها با ورودی بومی رنگ تنظیم می‌شوند. ترکیب ناخوانا ذخیره نمی‌شود.
دکمهٔ بازگرداندن پیش‌فرض فقط ظاهر را بازنشانی می‌کند. اتصال، کلیدها و سیاست تاریخچه حفظ می‌شوند.
متن‌ها ساده‌اند و دستور مدل یا متن واقعی اطلاع‌رسانی نگهداری را تغییر نمی‌دهند.
GET /gpante-support/v1/appearance فقط تنظیمات عمومی ظاهر را بدون cache برمی‌گرداند؛ هیچ تماس مدل یا دادهٔ گفتگو ندارد.
در هر بار بارگذاری صفحه، ظاهر تازه خوانده می‌شود تا صفحهٔ کش‌شده هم به تنظیم جدید برسد؛ تب از قبل باز را بازخوانی کنید.

= دکمه‌های راهنما و رفتار پنجره (0.4.0) =
در «چت پانته ← ظاهر» برای چهار دکمهٔ اختیاری، متن و لینک وارد کنید. متن خالی، دکمه را مخفی می‌کند. لینک باید HTTPS کامل یا مسیر داخلی مانند /shop/ باشد؛ متنِ واردشده بدون لینک معتبر ذخیره نمی‌شود. هیچ لینک نمونه‌ای از پیش فعال نیست.
دکمهٔ ارسال به‌شکل آیکون داخل کادر ترکیبی ورودی است؛ نام قابل تنظیم آن در tooltip و صفحه‌خوان استفاده می‌شود. عنوان کادر پرسش فقط برای صفحه‌خوان است. در focus، سایهٔ ملایم جای خط ضخیم را گرفته است.
توضیح ثابت بالای گفتگو به درخواست مدیر حذف شده است؛ سیاست مرکزی نگهداری، آرشیو ۳۰روزه و تأیید پاک‌کردن همان رفتار قبلی را دارند.
اندازهٔ پنجره حفظ شده است. Back مرورگر ابتدا چت را می‌بندد و Back بعدی به صفحهٔ قبلی می‌رود. ×، Escape و کلیک بیرون هم آن را می‌بندند؛ reload/Forward وضعیت باز را بازیابی می‌کند.

== Conversation archive (0.2.0) ==

Administrators can review anonymous conversations under Chat Pante → Conversations.
The authoritative archive is in the project's PostgreSQL database, not copied into WordPress.
Accepted questions, final answers and bounded error metadata remain accessible for 30 days
from the original question. Failed requests that never reached the backend are not conversations.
Administrators choose a global user-history period of 3, 7, 15 or 30 days and can disable clearing.
Clearing removes user access and AI context; it does not remove the administrative archive.
Expired or cleared user messages never return when the duration increases.
A separate private administrative connection key is required; the stored key is never rendered.
Read access closes at 30 days; the hourly retention job physically removes expired rows.
Backend migration 003 and workflow contract 2 must be deployed before upgrading the plugin.

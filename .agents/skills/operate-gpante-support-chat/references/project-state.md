# وضعیت نگهداری پروژه

به‌روز شده در ۲۰ اکتبر ۲۰۲۶. این سند، خلاصهٔ عمومی ادامهٔ کار است؛ وضعیت زنده همیشه باید دوباره خوانده شود. نسخه‌های قدیمی و مراحل پیش از تولید در تاریخچهٔ Git هستند. شناسه‌های استقرار، نسخه‌های فعال، پشتیبان‌ها، دفتر هزینه و رسیدهای عملیاتی را در ثبت خصوصی پروژه نگه دارید.

## نسخه و منبع

| جزء | مرجع جاری |
| --- | --- |
| افزونهٔ WordPress | **0.1.1**؛ [انتشار رسمی](https://github.com/vahid162/n8n-chat-gpante.com/releases/tag/wordpress-v0.1.1) |
| منبع افزونه | `wordpress-plugin/gpante-support-chat/`؛ schema تنظیمات 1 و REST API v1 |
| منابع workflow | `src/`، `scripts/build-workflow.cjs` و خروجی‌های `workflows/` |
| مهارت canonical | همین پوشه؛ **0.4.1**؛ نسخهٔ مهارت از افزونه و workflow مستقل است |
| راهنمای تولید | [نتیجه و روش بررسی](../../../../docs/production-readiness.md) |

کاربر افزونه را روی gpante.com نصب و فعال کرد و تکمیل راه‌اندازی عمومی را مجاز دانست. اتصال خصوصی آماده، نمایش عمومی روشن و مسیر واقعی سایت تا مدل بررسی شد. دستور قدیمیِ «سایت تغییر نکند» مربوط به مرحلهٔ ساخت محلی بود و برای همین راه‌اندازی با درخواست بعدی جایگزین شد؛ این اختیار به مدیریت نامرتبط سایت گسترش پیدا نمی‌کند.

## اصلاح و شواهد این مرحله

- نسخهٔ 0.1.0 برای محصولات دارای ویژگی و تصویر، رکوردهای `stdClass` ووکامرس را آرایه فرض می‌کرد. خطای کاتالوگ بازتولید شد؛ نسخهٔ 0.1.1 تبدیل همان رکوردهای قابل اعتماد را پیش از فهرست مجاز فیلدها انجام می‌دهد.
- آزمون رگرسیون ابتدا شکست خورد و پس از اصلاح، شکل آرایه/شیء، قیمت صفر و حذف فیلدهای خارج از فهرست عمومی را گذراند.
- ۴۰ آزمون Node، ۱۰ بررسی کاتالوگ PHP، تنظیمات/bridge، PHP lint، WPCS و پنج آزمون بسته/انتشار موفق‌اند. CI نسخهٔ اصلاحی نیز موفق شد.
- نصب از ZIP رسمی با تطبیق checksum و فایل‌های runtime انجام شد؛ تنظیمات و فعال‌بودن افزونه حفظ شدند.
- پوشش همهٔ محصولات عمومی موجود، صفحهٔ آخر و خارج از محدوده، فیلتر ترکیبی و سازگاری خروجی با ابزار بررسی شد. شمار محصولات ثابت یا سقف محصول نیست.
- مرورگر واقعی روی WoodMart: پاسخ محصول، لینک، کوکی امن، بازیابی گفتگو، جداسازی دو بازدیدکننده، حذف تاریخچه، خطا/تلاش مجدد و سه اندازهٔ صفحه بررسی شدند. جزئیات عمومی در گزارش تولید است؛ تصویرها و رسیدها خصوصی می‌مانند.
- اجرای طبیعی پاک‌سازی ساعتی نیز مشاهده شد. نسخه‌های زنده، نتیجهٔ اجراهای تازه و دفتر مالی را در ورود بعدی از سرویس بخوانید؛ این سند جای بررسی سلامت نیست.

## ادامهٔ بعدی

1. پیش از تغییر بعدی، Git و انتشار نصب‌شده، تنظیمات معتبر سایت، تعریف/نسخهٔ فعال workflow و اجراهای نگهداری را بخوانید و با منبع تطبیق دهید.
2. پشتیبان و رسیدهای خصوصی مرحلهٔ تولید، خارج از checkout عمومی نگهداری شده‌اند. آن‌ها را وارد PR، Release یا ZIP نکنید؛ پشتیبان کامل با JSON عمومی فرق دارد.
3. در استفادهٔ واقعی، کیفیت پاسخ‌ها، خطاها، مصرف و ظرفیت را بررسی کنید. بودجه و محدودیت‌ها را بدون درخواست کاربر افزایش ندهید. پیش از انقضای اعتبار تعرفه، قیمت و context مدل دوباره بررسی شوند.
4. سفارش، دانلود خریداری‌شده و ارجاع انسانی هنوز ساخته نشده‌اند. برای افزودنشان، نیاز، احراز هویت واقعی و کنترل مالکیت جداگانه تعریف شود.

Safari/iOS واقعی، multisite، همهٔ نسخه‌های حداقل و آزمون بار گسترده بررسی نشده‌اند. پاسخ موفق چند سناریو تضمین بی‌خطابودن مدل یا SLA نیست. در گم‌شدن پاسخ شبکه پس از ذخیره، تلاش مجدد ممکن است درخواست/هزینهٔ تازه بسازد؛ idempotency منطقی ارسال هنوز اضافه نشده است.

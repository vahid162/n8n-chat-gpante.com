# GPante Support Chat — WordPress 0.10.0

Public pages, posts and eligible products share an automatically maintained native WordPress search index. Standard site search and AI site discovery use the same selector. The active editor supplies static text; a malformed document is isolated and coverage is reported as incomplete.

Conversation history is paged without expanding model context. Recent activity renews the signed session cookie. Explicit retries reuse one send ID and replay a completed answer without another model charge. Visitors can rate their own visible answers and open native site search when AI is unavailable.

Main 1.7.0 strengthens source checks and per-recommendation price/attribute binding. Admin 1.3.0 adds bounded source/error diagnostics and privileged synthetic-test labels. Diagnostics retain at most 2,000 records for seven days without raw provider payloads or copied transcripts; the existing administrator archive remains 30 days.

Apply application migrations 004 and 005 before publishing the matching workflows. Existing settings, model, USD 2/month budget and call limits are preserved. The native index builds in bounded background batches; incomplete coverage is visible until reconciliation finishes. Reload existing browser tabs after upgrading.

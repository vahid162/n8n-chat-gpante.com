# GPante Support Chat 0.5.0

لینک‌های امن پاسخ دستیار به‌شکل دکمه نمایش داده می‌شوند. عنوان برجسته، پاراگراف‌های خوانا و جدول مشخصات دو‌ستونی، بررسی و انتخاب محصول را روی موبایل آسان‌تر می‌کنند. جدول عریض در محدودهٔ پیام قابل پیمایش است و متن نامعتبر بدون حذف اطلاعات به‌صورت متن نمایش داده می‌شود.

نمایش با DOM امن و بدون اجرای HTML مدل انجام می‌شود؛ کنترل مستقل مقصد لینک‌ها برقرار است. اندازهٔ پنجره، رنگ‌ها، تنظیمات اتصال/ظاهر، تاریخچه و سیاست نگهداری حفظ می‌شوند. این نسخه schema یا REST API تازه ندارد.

نسخهٔ 0.5.0 قابلیت نمایش جدول Markdown را اضافه می‌کند؛ برای تولید جدول‌های تازه، Main 1.2.3 قالب پاسخ را هماهنگ می‌کند. پاسخ‌های ساده و تاریخچهٔ قبلی همچنان خوانده می‌شوند.

نیازمندی‌ها: WordPress 6.6+، PHP 8.1+ و WooCommerce. ZIP رسمی `gpante-support-chat-wordpress-0.5.0.zip` را با گزینهٔ جایگزینی نصب کنید؛ افزونهٔ قبلی را حذف کامل نکنید. فایل `SHA256SUMS` برای بررسی دانلود همراه بسته است.

شواهد و حدود آزمون: [نمایش پاسخ‌های خوانا](../../specs/009-friendly-replies/verification.md). آزمون دستگاه فیزیکی، Safari/iOS و بار گسترده جداگانه‌اند.

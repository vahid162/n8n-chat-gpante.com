# GPante Support Chat 0.5.2

دکمه‌های لینک پاسخ دستیار زیر هم و تمام‌عرض نمایش داده می‌شوند؛ چند لینک در یک پاراگراف هم کنار هم نمی‌افتند. وزن متن دکمه‌ها معمولی شده و فضای لمس حداقل ۴۴ پیکسل حفظ شده است.

فاصلهٔ داخلی حباب‌ها، پاراگراف‌ها و ردیف‌های جدول کمتر شده است. قلم اصلی ۱۴ و جدول ۱۳ پیکسل، محتوای کامل، ابعاد پنجره، رنگ‌ها و تنظیمات قبلی حفظ می‌شوند. این اصلاح نمایش به تغییر n8n، SQL یا schema نیاز ندارد.

نیازمندی‌ها: WordPress 6.6+، PHP 8.1+ و WooCommerce. فایل `gpante-support-chat-wordpress-0.5.2.zip` را با جایگزینی نسخهٔ موجود نصب کنید؛ افزونه را حذف کامل نکنید. `SHA256SUMS` همراه بسته است. صفحهٔ باز را یک‌بار تازه کنید تا asset تازه دریافت شود.

# شواهد نسخهٔ 0.6.2

۲۱ اکتبر ۲۰۲۶؛ نامزد و سپس Release رسمی 0.6.2 نصب‌شده روی سایت بررسی شدند.

- ۸۰ آزمون Node موفق‌اند؛ سه رگرسیون اصلی پیش از اصلاح قرمز بودند: Online مستقل از انتظار پاسخ، history پیش از ارسال نامعلوم و rate limit بدون قطع اتصال. موارد اتصال مجددِ پاک‌کردن، انقضای متن پس از refresh ناموفق، guard تکرار، سیاست، focus و draft نیز بررسی شدند.
- PHP settings/appearance/bridge و ۲۴ بررسی query موفق‌اند؛ WPCS بدون خطا/هشدار است. دو کد ثابت بودجه/بازبینی سرویس بدون متن خصوصی backend آزموده شدند.
- نامزد روی قالب و ظاهر واقعی gpante.com در Chromium و Firefox، هرکدام در چهار اندازه بررسی شد: ۱۴۴۰×۱۰۰۰→۳۹۰×۶۵۰، ۳۹۰×۸۴۴→۳۷۴×۶۵۰، ۳۲۰×۵۶۸→۳۰۴×۴۸۰ و ۸۴۴×۳۹۰→۳۹۰×۳۶۶. سربرگ عادی حدود ۸۴٫۲ و کوتاه حدود ۶۶٫۲ پیکسل ماند؛ فضای پیام در کنترل‌های یکسان افزایش یافت، overflow صفر و دکمهٔ بستن ۴۴ پیکسل است.
- اتصال اولیه، سه‌نقطه، reduced-motion، خطای ارسال، شکست refresh با حفظ پیام، بازیابی پاسخ ذخیره‌شده، retry صریح، rate limit، offline/online و عنوان بلند بررسی شدند. همهٔ chat requestها پیش از سرور intercept شدند؛ پیام واقعی، تماس مدل و خطای runtime صفر بود. تصویر Firefox نیز دستی بازبینی شد.
- پنج آزمون Python بسته/انتشار و ساخت قطعی ۱۲ فایل runtime موفق‌اند؛ embed از همان template/assets بازسازی شد.
- ابزار قابل تکرار: `tests/chat-status-browser.py`؛ داده/تصویر آزمون و شناسه‌های استقرار خصوصی‌اند و در مخزن ثبت نمی‌شوند.

Safari/iOS و دستگاه فیزیکی آزمایش نشده‌اند. این تغییر idempotency منطقی یا ذخیرهٔ پیش‌نویس بین صفحات اضافه نمی‌کند؛ خواندن تاریخچه تضمین پایان پردازش همهٔ درخواست‌های قبلی نیست.

## انتشار و تولید

- PR 30 پس از موفقیت verify و archive-database ادغام و Release رسمی `wordpress-v0.6.2` از همان commit ساخته شد. ZIP دانلودشده با ساخت محلی و ۱۲ فایل source برابر است؛ SHA256: `aa7b2f86457e9aa091b4ddfd5e543e48fe76f45c0509e39364cd51fb834672e5`.
- پیش از نصب، drift همهٔ فایل‌ها/تنظیمات رد و پشتیبان محدود افزونهٔ قبلی و دو option خصوصی خارج webroot گرفته شد؛ هیچ transcript در این پشتیبان نیست. نصب با WP-CLI/PHP 8.3 انجام و نسخه/۱۲ فایل دوباره تطبیق داده شدند. runtime، کلیدها، کل appearance، enabled، سیاست/revision، فهرست افزونه‌ها و قالب برابر ماندند. cache فقط همین سایت پاک شد؛ سرویس مشترک restart نشد.
- همان سناریوهای Chromium/Firefox روی فایل نصب‌شده، هرکدام چهار اندازه، بدون تزریق candidate موفق‌اند. تمام chat requestها در این دور intercept شدند؛ صفر پیام واقعی/تماس مدل و صفر خطای runtime.
- در Chrome تازه و بدون mock، فقط تاریخچه/سیاست واقعی خوانده شد: state=ready، label=Online، اعلان پایین خالی، ورودی فعال و آیکون تزئینی aria-hidden. هیچ پیام ارسال نشد؛ شمار دفتر تماس مدل قبل/بعد ثابت بود.
- fingerprint تعریف/تنظیم/نسخه/فعال‌بودن هر ۲۵ workflow برابر ماند؛ Main 1.3.0 فعال و نسخهٔ published/draft برابر است. runtime بودجه و policy ثابت و آخرین Retention طبیعی موفق بود. SQL و پایگاه داخلی n8n تغییر نکردند.
- مهارت canonical نسخهٔ 0.8.2 و ZIP مستقل آن از چهار فایل همان منبع بازسازی شدند؛ نصب محلی همچنان به منبع canonical لینک است. شواهد خام، تنظیمات و شناسه‌های تولید خصوصی‌اند.

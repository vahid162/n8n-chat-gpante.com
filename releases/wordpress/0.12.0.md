# GPante Support Chat 0.12.0

چهار صفحهٔ موجود مدیریت خواناتر می‌شوند: نمای کلی اتصال، منابع، آمار هفت‌روزه و بودجهٔ ماه جاری UTC؛ گزارش منبع با فیلتر و صفحه‌بندی؛ کارت سؤال/پاسخ با تاریخ و زمان خوانا؛ پیش‌نمایش محلی ظاهر و نمایش وضعیت تنظیم‌شدن دو کلید خصوصی.

فیلتر و شمارهٔ صفحه هنگام رفتن به نشست و بازگشت حفظ می‌شوند. مسیر منابع به‌شکل ساختاریافته و دادهٔ خام مجاز پشت جزئیات است. شناسهٔ ناشناس قابل کپی، هزینهٔ کوچک USD بدون گردکردن به صفر و دادهٔ مفقود با عنوان «نامشخص» نمایش داده می‌شود. این گزارش درصد دقت پاسخ‌ها یا سلامت پیوستهٔ مدل را اعلام نمی‌کند.

پیش‌نمایش ظاهر از تغییرات ذخیره‌نشدهٔ همان صفحه استفاده می‌کند و چت یا شبکه راه نمی‌اندازد. بازنشانی کامل ظاهر تأیید می‌خواهد؛ حالت سایت/دستی، پالت دستی، متن‌ها، لینک‌ها و تنظیمات اتصال در ذخیرهٔ معمول حفظ می‌شوند. کلیدهای موجود نمایش داده نمی‌شوند؛ فیلد خالی کلید قبلی را نگه می‌دارد.

پیش از نصب، به‌ترتیب migration تابعی007 و Admin1.4.0 آماده و بررسی شوند؛ سپس افزونه ارتقا یابد.007 فقط تابع خصوصی مدیریت را تغییر می‌دهد؛ تاریخچه، دفتر مالی، بودجه، سیاست و محافظ ارسال006 حفظ می‌شوند. Main1.7.1 و Retention1.2.0 تغییر نمی‌کنند و006 دوباره اجرا نمی‌شود. ZIP این نسخه۱۹فایل runtime دارد؛ schema اتصال۲، ظاهر۳ و قراردادهای عمومی فعلی ثابت‌اند.

۱۷۱ آزمون Node، ۲۹ Python، ۹ مجموعهٔ PHP و هفت مجموعهٔ SQL ایزوله موفق‌اند. بررسی بومی WordPress7.1.3/WooCommerce11.2.1 و Chromium156، نه گروه شامل چهار صفحه، مسیر بازگشت، کپی، پیش‌نمایش، بازنشانی و جست‌وجوی `0` را بدون پیام واقعی یا تماس مدل گذراند؛ اعتبارسنج n8n2.44.6 نیز Admin1.4.0 پیشنهادی را بدون warning پذیرفت. تنها یافتهٔ بازبینی اصلاح و بازآزمون شد و یافتهٔ حل‌نشده‌ای باقی نیست.

این یادداشت برای نامزد انتشار است؛ بسته‌سازی، انتشار رسمی و نصب هنوز تأیید نشده‌اند. نسخهٔ زندهٔ آخرین بازخوانی۲۸اکتبر۲۰۲۶،0.11.0 است. [رفتار، ترتیب ارتقا و وضعیت شواهد](../../docs/admin-experience.md).

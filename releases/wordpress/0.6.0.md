# GPante Support Chat — WordPress 0.6.0

جست‌وجوی دسته‌بندی، تازه‌ها و پرفروش‌های واقعی به provider عمومی افزوده شده است. مقاله‌ها بر اساس ارتباط عنوان و سپس تاریخ مرتب می‌شوند؛ «کورل»، CorelDRAW و عبارت‌های تبدیل/تغییر، نتایج مرتبط‌تری می‌دهند.

- فیلتر دسته و زیردسته برای محصول و مقاله، با منبع مستقل هرکدام و صفحه‌بندی کامل.
- جدیدترین بر اساس انتشار؛ پرفروش بر اساس تعداد ثبت‌شدهٔ کل دورهٔ WooCommerce، شامل سفارش رایگان و با حذف موارد بدون فروش ثبت‌شده.
- دسته‌های صرفاً خصوصی، پنهان یا رمزدار در پیشنهادها ظاهر نمی‌شوند. دادهٔ مشتری، سفارش و تعداد خام فروش منتشر نمی‌شود.
- تنظیمات اتصال، کلیدها، ظاهر، تاریخچه و ابعاد چت حفظ می‌شوند؛ schema و REST v1 تغییر ناسازگار ندارند.

نیازمندی: WordPress 6.6+، PHP 8.1+ و WooCommerce فعال. سازگاری بومی با WordPress 7.1.3 و WooCommerce 11.2.1 بررسی شده است. برای استفادهٔ مدل از ابزارهای جدید، Main 1.3.0 نیز لازم است؛ ابتدا افزونه و سپس Main ارتقا یابند. آزمون‌های کاتالوگ، اعتبارسنجی ابزار و بسته همراه منبع‌اند؛ [سناریو و شواهد](https://github.com/vahid162/n8n-chat-gpante.com/blob/main/specs/010-catalog-discovery/verification.md).

فایل `gpante-support-chat-wordpress-0.6.0.zip` را از Assets دریافت و checksum را با `SHA256SUMS` مقایسه کنید. ZIP کد منبع کل مخزن، بستهٔ نصب وردپرس نیست. تنظیم تازه یا بازنشانی لازم نیست. این نسخه جست‌وجوی عمومی را توسعه می‌دهد؛ «پرفروش ۳۰ روز اخیر» و جست‌وجوی معنایی برداری در آن نیست.

# ظاهر قابل تنظیم چت

درخواست: مدیر سایت بتواند متن‌ها و رنگ‌های پیش‌فرض رابط را از پیشخوان تغییر دهد.

- صفحهٔ مستقل و قابل پیدا کردن «چت پانته ← ظاهر»، مخصوص manage_options، با ذخیرهٔ بومی و nonce.
- هشت متن اصلی: عنوان، زیرعنوان، دکمهٔ بازکردن، خوشامد، عنوان/راهنمای ورودی، ارسال و گفتگوی تازه.
- هشت رنگ: رنگ اصلی و متن آن، سطح، متن، بخش پیام‌ها، پیام کاربر/دستیار و نوار تزئینی.
- متن ساده و محدود، رنگ شش‌رقمی، حداقل خوانایی ۴٫۵؛ دادهٔ نامعتبر قبلی را پاک نکند.
- بازگرداندن پیش‌فرض فقط برای ظاهر؛ اتصال خصوصی، enabled و سیاست آرشیو حفظ شوند.
- متن حقوقی/واقعی نگهداری و تأیید پاک‌کردن تغییر نکنند. خوشامدگویی دستور مدل نیست.
- صفحات کش‌شده ظاهر جدید را در بارگذاری بعدی دریافت کنند؛ شکست دریافت مانع چت نشود.
- راست‌به‌چپ، خوانایی، دسترس‌پذیری کنترل‌ها، موبایل و نمایشگر کوتاه حفظ شوند.

خارج از این درخواست: CSS/HTML دلخواه، فونت/آواتار/جابجایی، پیش‌نمایش سازنده، updater اختصاصی، تغییر مدل یا schema پروژه.
